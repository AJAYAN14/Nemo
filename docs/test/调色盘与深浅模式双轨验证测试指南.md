# Nemo 调色盘规范与深浅模式双轨验证测试指南

> **文档目标**：指导 QA 人员与开发者全面验证全应用在「浅色模式」与「深色模式」下的色彩质感、表面明度阶梯、阴影纯净度及动态强调色自发光补偿，确保 100% 对齐项目调色盘规范（`docs/design/color-palette/COLORS.md` 与 `docs/design/Dynamic_Color_System_Spec.md`）。

---

## 一、本次色彩治理核心问题复盘

| 缺陷类别 | 修复前表现（避坑反面） | 修复后标准表现（规范正解） |
| :--- | :--- | :--- |
| **弥散阴影透光显脏** | 卡片使用了 `.softCardShadow()` 弥散软阴影，但卡片背景被设置成带有透明度的半透明色（如 `cardBackground.copy(alpha = 0.85f)` 或 `0.95f`）。导致卡片下方的黑色模糊阴影穿透卡片背底，卡片内部像蒙了层脏灰，视觉混沌。 | 卡片容器底色彻底重构为 **100% 绝对不透明纯色**（浅色 `#FFFFFF` 纯白，深色 `#1C1C1E` 深石板灰）。软阴影仅在卡片外部漫反射自然上浮，卡片内部绝对纯净通透。 |
| **深浅模式混用同色** | 强调色（红、橙、黄、绿、青、蓝、紫）直接写死浅色常量（`IosColors.X`），在深色纯黑背景下明度不足，被 OLED 纯黑吞噬，视觉暗沉、对比度缺失。 | 严格遵循**光学明度补偿公理**，深色模式全面升级为自发光高亮补偿色（`IosColors.XDark`，如自发光霓虹蓝 `#0A84FF`、高荧光绿 `#30D158`、柔和自发光红 `#FF453A`）。 |
| **散落杂色与灰阶脱节** | 页面内残留 Tailwind 散色（如 `NemoNeutrals.Gray400`、`Gray100` 等），二级副文本深浅同色（`#9CA3AF`），违背四级对比度阶梯。 | 文本四级阶梯完全收敛至：一级主文本（浅色 `#000000` / 深色 `#FFFFFF`）、二级次文本（浅色 `#8A8A8E` / 深色 `#8E8E93`）；分割线对齐标准发丝线（浅色 `#C6C6C8` / 深色 `#38383A`）。 |

## 二、重点界面验证清单与测试步骤

### 1. SRS 核心学习卡片（单词与语法卡片）
- **测试路径**：首页 -> 点击「继续学习」/「开始复习」-> 进入单词/语法卡片学习页。
- **界面文件**：
  - [`SRSLearningCard.kt`](file:///e:/Android/Nemo/feature/learning/src/main/java/com/jian/nemo/feature/learning/presentation/components/cards/SRSLearningCard.kt)
  - [`SRSGrammarCard.kt`](file:///e:/Android/Nemo/feature/learning/src/main/java/com/jian/nemo/feature/learning/presentation/components/cards/SRSGrammarCard.kt)
- **视觉验证重点**：
  1. **正面卡片与手绘板框**：观察卡片表面底色。浅色模式下应为清澈无瑕的绝对纯白（`#FFFFFF`），被屏幕底层的浅灰（`#F2F2F7`）自然托起；深色模式下为温润深石板灰（`#1C1C1E`），无任何黑色阴影透光反黑。
  2. **翻转背面（释义与例句区域）**：点击卡片或点击底部「显示答案」翻面，观察背面卡片。卡片底色完全平整不透明，即使在强光或暗光下观察，卡片中心与边缘明度均一，彻底消除了旧版的蒙灰感。
  3. **次级标签与词性胶囊**：词性胶囊（如「名」、「动」）采用 Level 2 二级表面（浅色 `#E5E5EA` / 深色 `#2C2C2E`），副文本采用 `#8A8A8E` / `#8E8E93`，文字对比度清晰柔和。

## 三、深浅模式切换与环境测试方法

### 方式 1：Android 系统原生切换（最快端到端体验）
1. 在 Android 设备或模拟器顶部状态栏下滑，展开系统快捷开关面板；
2. 点击「深色主题 / 深色模式（Dark theme）」开关进行一键切换；
3. 返回 Nemo 应用，界面瞬间响应主题切换，观察各个页面是否呈现平滑自然的色彩过渡，重点检查卡片边界和文字对比度。

### 方式 2：应用内外观设置切换
1. 打开 Nemo -> 点击底部「我的」Tab -> 点击右上角「设置」图标；
2. 进入「外观风格」或「主题设置」；
3. 依次手动选择「浅色模式」与「深色模式」，实时预览界面响应。

### 方式 3：Android Studio Layout Inspector 像素级抓取
1. 将设备连接至 Android Studio，打开 **Tools -> Layout Inspector**；
2. 选中目标卡片（如 `SRSLearningCard` 的容器 `Surface` 或 `Box`）；
3. 在右侧 Attributes 面板中查看其 Background 颜色属性：
   - 浅色模式必须精确命中：`#FFFFFFFF`；
   - 深色模式必须精确命中：`#FF1C1C1E`；
   - 确认其 Alpha 通道为 `1.0`（无任何非 1.0 的透明度衰减）。

## 四、权威色值对照速查表 (WCAG AAA 级合规基准)

| 语义角色 Token | 浅色模式色值 (Light) | 深色模式色值 (Dark) | 典型应用组件 |
| :--- | :---: | :---: | :--- |
| **`bg_canvas` (画布基底)** | `#F2F2F7` | `#000000` (OLED纯黑) | 全屏 Scaffold、页面顶底最深处 |
| **`surface_card` (一级卡片)** | `#FFFFFF` | `#1C1C1E` (~11% 亮度) | 单词卡、设置分组卡、测试选择卡 |
| **`surface_subcard` (二级表面)** | `#E5E5EA` | `#2C2C2E` (~17% 亮度) | 次级操作胶囊、词性标签背景、进度条滑槽 |
| **`surface_elevated` (三级部件)** | `#D1D1D6` | `#3A3A3C` (~23% 亮度) | 分段控件滑块、高亮按压态 |
| **`separator` (发丝分割线)** | `#C6C6C8` | `#38383A` | 卡片行间分割线、微光边框 |
| **`text_primary` (一级文字)** | `#000000` | `#FFFFFF` | 页面标题、核心单词、重点数字 |
| **`text_secondary` (二级文字)** | `#8A8A8E` | `#8E8E93` | 副标题、假名音标、说明描述 |
| **`accent_blue` (核心交互蓝)** | `#007AFF` | `#0A84FF` (自发光霓虹蓝) | 主按钮、选中态指示器、链接 |
| **`accent_green` (成功/正向绿)** | `#34C759` | `#30D158` (高荧光绿) | 掌握状态、完成标记、正确指示 |

| **`accent_orange` (重点/关注橙)** | `#FF9500` | `#FF9F0A` (温润琥珀橙) | 收藏星标、进行中状态、活动环 |
