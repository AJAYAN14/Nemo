## 6. 总结与后续规范整改行动路线图

经过本次全面深入的代码与资源资产审查（已剔除用户当前正在修改的 20 个工作区文件），Nemo 项目当前存在的存量规范技术债务主要集中在以下三个梯队：

1. **第一梯队（阻断级 UI 资产规范，建议优先治理）**：
   - 收编清理 `TestColors.kt` 及业务 Screen 中残留的 700+ 处裸色值，全量回归 `:core:designsystem` 的 `Color.kt` 语义 Token；
   - 启动 UI 文本国际化收编专项，为 `feature/settings`、`feature/statistics` 等各 Feature 模块建立 `strings.xml`，收编硬编码文本。

2. **第二梯队（阻断级代码纯净度规范）**：
   - 清理源码中遗留的 92 处“复刻旧项目”、“参考旧项目”等溯源元注释，将溯源信息转移至 Git 提交信息中。

3. **第三梯队（架构与命名纪律优化）**：
   - 拆解 `AppUtils.kt`、`DateTimeUtils.kt` 等垃圾桶工具类为 Kotlin 规范扩展（`ContextExt.kt` 等）；
   - 重构数据源层中的 `*DataManager` 为 `*DataSource`；
   - 重命名 `src/androidTest/` 下的 7 个测试文件为 `*UiTest.kt`；
   - 修复 Composable 参数顺序与布尔函数命名违规。
