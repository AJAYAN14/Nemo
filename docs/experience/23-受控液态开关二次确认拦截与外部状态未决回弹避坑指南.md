# 受控液态开关二次确认拦截与外部状态未决回弹避坑指南

> 本文档记录在带有二次确认弹窗或异步拦截的设置项中，因开关内部手势动效“提前抢跑”且 Compose 副作用 Key 缺乏状态未决感知，导致取消操作后产生视觉“假关闭”的问题剖析、受控重置架构与工程避坑原则。

---

## 一、 四列核心经验对照表

| 坑是什么（Problem & Root Cause） | 怎么避（Resolution & Practice） | 相关工具 / 文件 | 统一原则（Principle） |
| :--- | :--- | :--- | :--- | :--- |
| **坑 1：手势拖拽松手提前修改内部状态造成假关闭**<br>开关组件（`LiquidToggle`）在用户拖拽松手或轻点时，内部强行将 `fraction` 动画吸附到了目标位置（`0f` 或 `1f`）并触发 `onSelect` 回调。但当外部业务存在二次确认弹窗拦截时，实际底层数据并未更新。如果用户点击弹窗【取消】，弹窗关闭而底层真实状态保持原值（仍为 `true`）。此时开关视觉停留在关闭位置，形成数据与界面割裂的“假关闭”。 | **构建基于外部重置信号的双向受控机制**：<br>1. 为开关组件增加无侵入的可选重置信号参数 `resetSignal: Any? = null`；<br>2. 副作用监听升级为 `LaunchedEffect(selected(), resetSignal)`；<br>3. 当外部用户点击取消或 Dismiss 弹窗时，递增 `resetSignal` 唤醒组件检查；若当前内部动效位置与真实状态不符（`fraction != target`），立即调用阻尼弹簧动画（`dampedDragAnimation.animateToValue`）平滑弹性弹回原位。 | `LiquidToggle.kt`<br>`SettingsScreen.kt`<br>`LaunchedEffect`<br>`dampedDragAnimation` | **受控组件状态闭环公理**<br>所有具备手势内部动效的开关/选择组件，必须具备在外部数据未采纳或取消时自动回弹复位的能力，杜绝出现视觉与数据脱节的假状态。 |
| **坑 2：Compose 副作用依赖单一状态值导致无法感知同态撤销**<br>开关原内部副作用仅依赖 `selected()` 外部布尔值（`LaunchedEffect(selected())`）。在取消操作链路中，外部数据始终为 `true`（从未变成 `false`），对 Compose 调度器而言 Key 从始至终没有改变，导致该副作用直接被跳过，根本无法执行任何回弹恢复逻辑。 | **信号依赖与状态校验解耦**：<br>将外部动作通知抽象为可变版本信号（Version/Trigger），与纯状态数据一并纳入 `LaunchedEffect` 的 Key 中。每次发生取消拦截均主动发射变更信号，迫使组件重新核验内部几何位置与单一真实数据源的一致性。 | `SettingsScreen.kt`<br>`mutableIntStateOf`<br>`resetSignal` | **事件信号解耦原则**<br>当需要通知子组件对“状态未改变”的撤销或取消事件做出视觉反应时，必须引入显式版本信号驱动副作用执行，严禁仅依靠被取消的状态字段本身。 |

## 二、 落地规范与关键代码对比

### 1. 规整前后的 LiquidToggle 状态同步对比

```kotlin
// 🔴 错误做法：仅监听 selected()，当外部弹窗取消时 key 恒为 true 无法触发回弹
@Composable
fun LiquidToggle(
    selected: () -> Boolean,
    onSelect: (Boolean) -> Unit,
    ...
) {
    ...
    LaunchedEffect(selected()) {
        val target = if (selected()) 1f else 0f
        if (target != fraction) {
            fraction = target
            dampedDragAnimation.animateToValue(target)
        }
    }
}

// 🟢 正确规范：引入可选 resetSignal 信号，在外部撤销时强制校验并弹簧回弹
@Composable
fun LiquidToggle(
    selected: () -> Boolean,
    onSelect: (Boolean) -> Unit,
    modifier: Modifier = Modifier,
    backdrop: Backdrop? = null,
    accentColor: Color? = null,
    resetSignal: Any? = null
) {
    ...
    LaunchedEffect(selected(), resetSignal) {
        val target = if (selected()) 1f else 0f
        if (target != fraction) {
            fraction = target
            if (!isInitialized) {
                dampedDragAnimation.snapToValue(target)
            } else {
                dampedDragAnimation.animateToValue(target)
            }
        }
    }
}
```

### 2. 设置界面弹窗取消闭环实现

```kotlin
// 状态层定义重置计数器
var showRandomNewContentConfirmDialog by remember { mutableStateOf(false) }
var randomNewContentResetSignal by remember { mutableIntStateOf(0) }

// 开关绑定重置信号，并防同态无效触发
LiquidToggle(
    checked = uiState.isRandomNewContentEnabled,
    onCheckedChange = { next ->
        if (next != uiState.isRandomNewContentEnabled) {
            showRandomNewContentConfirmDialog = true
        }
    },
    accentColor = MaterialTheme.colorScheme.primary,
    resetSignal = randomNewContentResetSignal
)

// 弹窗取消时（包含蒙层 Dismiss 与取消按钮）主动发射信号回弹
NemoDialog(
    onDismissRequest = {
        showRandomNewContentConfirmDialog = false
        randomNewContentResetSignal++
    },
    ...
    onDismiss = {
        showRandomNewContentConfirmDialog = false
        randomNewContentResetSignal++
    }
)
```
