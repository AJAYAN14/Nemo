## 经验编写与维护规范
1. **四列格式**：每篇经验文件必须包含四列对照表（“坑是什么 → 怎么避 → 相关工具/文件 → 统一原则”）。
2. **单一数据源**：新发现的技术坑点与最佳实践需在本文档登记索引。
3. **归档机制**：当活跃经验文件超过 5 份时进行阶段性归纳与归档。
