# 38-全工程顶栏最高字重与官方原生饱满图标迁移避坑指南

> 记录将全工程顶栏所有功能按钮（返回、刷新、重置、添加、分享）及分类胶囊文字全面迁移至 Google Fonts 官方原生最大字重（`wght700` / `W900`）的工程实践与避坑要点。

---

## 核心复盘与避坑对照

| 坑是什么 | 怎么避 | 相关工具 / 文件 | 统一原则 |
| :--- | :--- | :--- | :--- |
| **顶栏功能按钮线条偏细与分量参差**<br>常规细线条图标（如 `KeyboardArrowLeft`、`Refresh`、`Add`、`Replay`）在 48dp 画廊级大液态玻璃按钮中线宽偏细，且两端视觉分量不均。 | **全面升级至 Google Fonts 官方最高字重**：统一采用官方原生 `wght700`（Bold / Heavy）圆角矢量定义（`ic_arrow_back_ios_wght700`、`ic_refresh_wght700`、`ic_replay_wght700`、`ic_add_wght700`、`ios_share_wght700`），严格遵循 AAPT 空格规范展开。 | `CommonHeader.kt`<br>`CloudBackupHistoryScreen.kt`<br>`StorageManagementScreen.kt`<br>`AdvancedLearningSettingsScreen.kt`<br>`AISettingsScreen.kt`<br>`ActivityHeatmapScreen.kt` | **官方优先与视觉分量平衡公理**：全工程顶栏操作按钮统一使用 Google 官方原生最高字重圆角矢量。 |
| **Compose 自带 ArrowBackIos 线条单薄且内折角尖锐（假加粗）**<br>直接使用 Compose 库内置的 `ArrowBackIos` 图标时，其笔画法线厚度仅 2.0（仍是 Regular 细线），且内拐角为 `lineTo` 直角折线。单纯放大尺寸只会导致图标被强行拉大撑满（傻大），视觉上线条依然单薄、折角僵硬不圆润。 | **引入 Material Symbols Rounded wght700 矢量并恢复 22dp 精致留白**：采用带有连续二次贝塞尔圆角（`Q` / `T` 曲线）的官方最高字重矢量，尖端与两端完全圆头，笔画加厚 2 倍；尺寸收敛至 `22.dp`，在 48dp 液态玻璃底座内形成舒展精致的留白。 | `ic_arrow_back_ios_wght700.xml`<br>`CommonHeader.kt`<br>`LibraryListComponents.kt`<br>`LoginScreen.kt`<br>`LiquidGlassLabScreen.kt` | **真正字重与呼吸感留白法则**：图标字重必须依赖矢量路径自身的加厚与圆弧过渡，绝不可通过盲目放大容器来充当加粗；图标尺寸与外层底座必须保留适度的留白呼吸感。 |
| **分类胶囊文字与空心图标分量单薄**<br>词库列表（语法、单词）DiscoveryBar 选中态仅为常规 Bold，未学习图标为空心沙漏，与加粗顶栏对比缺乏冲击力。 | **字重升至顶格 Black (W900) + 全量实心**：选项卡未选中态提升为 `Bold (W700)`，选中态直达最大字重 `Black (W900)`；未学习图标由 `HourglassEmpty` 升级为实心 `HourglassFull`，消除空心与实心混杂。 | `DiscoveryBar.kt`<br>`LibraryListComponents.kt` | **视觉权重均质化与实心饱满原则**：顶栏高频选择项统一使用实心饱和图标并配合最高字重，建立极致扎实的秩序感。 |
| **顶栏标题与加粗按钮首尾失衡**<br>返回按钮加粗后，若标题保持默认细文本，会导致左重右轻。 | **主标题统一同步加粗**：`CommonHeader` 中 `title` 统一样式继承并叠加 `FontWeight.Bold`，建立从左侧返回键、主标题到右侧 Actions 浑然一体的高级质感。 | `CommonHeader.kt` | **顶栏整体视觉平衡公理**：顶栏左中右各槽位元素分量必须保持一致的重力感。 |
| **返回键锯齿与光学视觉偏置（非对称负空间）**<br>矢量固有尺寸定义过小（24dp）在放大渲染时产生拉伸锯齿；单纯几何包围盒居中导致左侧尖角冲力过强、右侧镂空太大产生向左偏的错觉。 | **超采样抗锯齿 + 严格对齐 ShapeShifter X: 6.05 光学视觉居中**：矢量固有尺寸提升至 48dp 彻底消灭缩放锯齿；平移量精准对齐 `X: 6.05`（平移 +4.75，尺寸 11.32×20.07），为右侧负空间保留宽适呼吸感，视觉绝对咬合圆心。 | `ic_arrow_back_ios_wght700.xml` | **光学补偿与超采样抗锯齿法则**：非对称指向性符号严禁冰冷几何居中，必须尊重负空间与视觉锚点做光学微调；矢量基准分辨率必须对齐物理渲染底座。 |
| **顶栏残留细线条图标（撤销、假名切换、三点菜单过小）**<br>顶栏部分操作按钮若仍遗留 Compose 内置细线图标或小半径圆点，会在加粗顶栏中形成强烈的视觉割裂感。 | **全量排查并落地官方原生 wght700 矢量与加粗大圆点**：撤销按钮升级为 `ic_undo_wght700`；假名切换升级为 `ic_swap_horiz_wght700`；三点菜单半径自 2.9dp 提升至 3.6dp，全工程顶栏达成 100% 均质最高字重。 | `ic_undo_wght700.xml`<br>`ic_swap_horiz_wght700.xml`<br>`LearningCommonComponents.kt`<br>`KanaChartScreen.kt`<br>`NemoGlassMenuView.kt` | **顶栏全量均质化原则**：凡居于顶栏的图标资产与操作控件，一律必须拥有最高字重（wght700 / W900），绝不允许细线杂混。 |
| **返回与撤销图标尺寸比例失调（28dp 过大/24dp 偏小）**<br>在 48dp 的圆形画廊级液态玻璃底座中，24dp 留白偏宽缺乏视觉张力，28dp 贴近边缘略显拥挤。 | **统一收敛至 26.dp 黄金尺度**：全工程返回按钮（`CommonHeader`、`LibraryListComponents`、`LoginScreen`、`LiquidGlassLabScreen`）与学习界面撤销按钮（Undo）统一设为 `26.dp`，外层留白 11dp，兼具力量感与高级通透呼吸感。 | `CommonHeader.kt`<br>`LearningCommonComponents.kt`<br>`LibraryListComponents.kt`<br>`LoginScreen.kt`<br>`LiquidGlassLabScreen.kt` | **底座与图标比例黄金平衡律**：48dp 圆形液态玻璃底座内，单图标最佳展示尺寸为 `26.dp`（占比约 54.2%），达成极致舒适的视觉重心与留白。 |
| **胶囊计数标签字号偏小与字重单薄导致溢出或失衡**<br>学习顶栏“剩余数量”胶囊原使用 `labelMedium (12sp)`，字重为 Medium/Bold，文字显得细弱不清晰；若直接改大又容易超出胶囊边界。 | **14sp 字号 + ExtraBold/Black 字重 + 单行防溢出硬约束**：前缀字重提升至 `FontWeight.ExtraBold (W800)`，数字提升至 `FontWeight.Black (W900)`，字号微调至 `14.sp`；显式声明 `maxLines = 1, softWrap = false`，搭配 48dp 高度胶囊自适应，既浑厚醒目又绝不折行溢出。 | `LearningCommonComponents.kt` | **胶囊信息排版稳定性原则**：动态计数标签必须同时兼顾高可见度字重与单行截断安全线，确保在各类数字长度下均不破坏容器比例。 |
