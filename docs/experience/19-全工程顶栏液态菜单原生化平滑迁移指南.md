# 19-全工程顶栏液态菜单原生化平滑迁移指南

> 记录 Nemo 项目将生词本（收藏库/错题本）、词库等级筛选、测试顶栏等全工程操作菜单全面接入原生液态毛玻璃菜单引擎（`NemoGlassMenuView` + `GlassMenuOverlay` + 弹性拉伸物理机制）的架构设计、迁移范式与避坑实践。

## 核心避坑复盘对照表

| 坑是什么 | 怎么避 | 相关工具 / 文件 | 统一原则 |
| :--- | :--- | :--- | :--- |
| **手势竞争与双层浮层重叠**：业务层既使用 Compose 的 `NemoLiquidMenuOverlay`，又挂载底层原生 `GlassMenuOverlay`，导致长按时手势短路并引发画面重复绘制 | 上层 `*Overlay` 仅负责组装数据项与回调注册，通过全局状态桥接（`ActiveNative*Items`）向原生引擎注入菜单项，不再重复渲染 Compose 浮层，手势由全局原生 Window 单一接管 | `CollectionActionMenu.kt`<br>`LibraryListComponents.kt`<br>`TestHeaderComponents.kt` | **单一捕获与零破坏适配公理**：保留原业务界面对外组件签名，底层通过单向注册状态彻底抽离为原生视图引擎，杜绝手势竞争。 |
| **业务弹窗与原生菜单生命周期断层**：菜单项点击后需要二次确认（如生词本清空弹窗），若原生菜单未关闭即弹窗，会导致焦点错乱或弹窗被手势遮罩屏蔽 | 原生菜单项分发回调先执行 `onDismiss()` 触发物理收起，再开启对应业务 `NemoDialog` 的展示状态，确保原生浮层与 Compose 弹窗生命周期平滑衔接 | `CollectionActionMenu.kt`<br>`NemoDialog.kt` | **时序解耦原则**：原生菜单收起与高层业务对话框展开采用明确的时序触发，保证手势捕获安全移交。 |
| **动态等级与选中标记状态联动延迟**：多级筛选菜单（如 N5~N1）在切换后，菜单内部勾选态与列表数量未即时响应，导致视觉残留 | 利用 `remember(selectedLevel, countsByLevel, ...)` 深度感知外部状态，并在 `SideEffect` 中同步更新活跃菜单项列表，保证原生引擎每帧绘制均能取到最新选中状态（`checked = isSelected`） | `LibraryListComponents.kt`<br>`GlassMenuItemRecord.kt` | **状态单向流入原则**：菜单状态完全受控于上层单一数据源，通过 SideEffect 零时差桥接至原生引擎。 |
| **图标资产格式不统一**：测试模块暂停与收藏等业务图标在原生 Canvas 中缺少对应的矢量 Path，导致直接降级甚至渲染异常 | 在原生 `GlassIcons` 单例中扩充高品质贝塞尔矢量 Path（如新增 `pause` 双矩形纯净路径、`heart` 轮廓等），统一纳入原生 Canvas 渲染流水线 | `GlassIcons.kt`<br>`GlassMenuItemRecord.kt` | **原生矢量资产单一标准原则**：原生液态菜单所有图标统一采用 Canvas 纯净贝塞尔 Path，彻底杜绝混杂位图与第三方库。 |

## 架构演进与接入范式

### 1. 全局桥接三件套
对于任意包含操作菜单的子模块，统一声明三项局部全局状态：
```kotlin
internal val ActiveNativeXxxMenuItems = mutableStateOf<List<GlassMenuItemRecord>>(emptyList())
internal val ActiveNativeXxxActionHandler = mutableStateOf<((String) -> Unit)?>(null)
internal val ActiveNativeXxxOpenState = mutableStateOf(false)
```

### 2. 按钮组件（XxxButton）接入
在按钮内部利用 `NemoNativeLiquidMenuTrigger` 桥接，深浅色自适应当前背景明度：
```kotlin
val items = ActiveNativeXxxMenuItems.value
val isDarkTheme = MaterialTheme.colorScheme.background.luminance() < 0.5f

if (items.isNotEmpty()) {
    NemoNativeLiquidMenuTrigger(
        items = items,
        modifier = modifier,
        buttonSize = buttonSize,
        colorScheme = if (isDarkTheme) "dark" else "light",
        menuWidth = 260.dp,
        onSelect = { item, _ -> ActiveNativeXxxActionHandler.value?.invoke(item.id) },
        onOpenChange = { open ->
            ActiveNativeXxxOpenState.value = open
            if (open != isExpanded) onClick()
        },
        content = content
    )
} else {
    // 兼容退化分支
    NemoLiquidMenuButton(...)
}
```

### 3. 浮层组件（XxxOverlay）注入
浮层不再绘制多余全屏内容，改为在生命周期中构建数据并写入状态：
```kotlin
val nativeItems = remember(...) {
    listOf(
        GlassMenuItemRecord(id = "...", title = "...", icon = "...", checked = ...),
        GlassMenuItemRecord(separator = true),
        ...
    )
}

SideEffect {
    ActiveNativeXxxMenuItems.value = nativeItems
    ActiveNativeXxxActionHandler.value = { id ->
        onDismiss()
        handleAction(id)
    }
}
```
