## 规范检查清单
1. **图标**：100% Google Fonts 原生 Material 实心图标（`Icons.Rounded.*`），0 第三方杂合图标。
2. **尺寸与曲率**：底框与图标严格符合 2:3 黄金比例，底框必须使用 G2 连续平滑曲率 `RoundedRectangle`。
3. **双轨架构**：柔和微透与活力纯色共享同一基准颜色，单 Box + 单 Icon 计算属性复用。
4. **顶栏规范**：统一 48dp `CommonHeader` + 四阶垂直渐变遮罩 + 动态状态栏避让。
