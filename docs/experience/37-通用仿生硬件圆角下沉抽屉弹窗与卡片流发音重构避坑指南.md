# 37-通用仿生硬件圆角下沉抽屉弹窗与卡片流发音重构避坑指南

> 本文档记录在 Nemo 中引入高质感仿生硬件圆角下沉抽屉弹窗（`NemoPageBottomSheet`）、配套自适应居中模态顶栏（`NemoSheetTopBar`），以及完成语音参数设置界面双抽屉弹窗迁移的踩坑与落地经验。

---

## 避坑核心对照表

| **1. 试验性 API 与多平台视口尺寸漂移**<br>试图通过 `LocalWindowInfo.current.containerDpSize` 计算屏幕高度导致编译失败（`Unresolved reference 'containerDpSize'`）。 | **视口尺寸单一稳定来源**：统一基于 `LocalConfiguration.current.screenHeightDp.dp` 结合 `WindowInsets.statusBars` 计算可用视口高度，安全跨多版本。 | `NemoPageBottomSheet.kt`<br>`LocalConfiguration`<br>`WindowInsets.statusBars` | **视口尺寸单一稳定来源公理**：全局视口与窗口边界计算统一遵循 `LocalConfiguration` 标准度量，杜绝实验性/未公开字段。 |
| **2. 低版本系统硬件圆角读取崩溃**<br>`WindowInsets.getRoundedCorner` 仅在 API 31+ 引入，低版本直接读取会导致编译警告或运行时 `NoSuchMethodError`。 | **API 分级探测与优雅保底**：在 `deviceCornerShape` 中增加 `Build.VERSION.SDK_INT >= Build.VERSION_CODES.S` 运行时守卫，低版本安全保底为 36.dp G2 连续平滑圆角。 | `DeviceCornerShape.kt`<br>`UnevenRoundedRectangle.kt`<br>`RoundedCorner` | **硬件感知与向下无感保底公理**：高阶硬件物理特性探测必须配备运行时 API 版本守卫，无论任何设备形态均具备高确定性视觉兜底。 |
| **3. 抽屉弹窗回弹漏底与边缘破裂**<br>弹性物理弹簧（Spring）在向上冲刺至极点或向下拖拽时，底部可能产生毫秒级微缝隙露出底层画布。 | **底部 32dp 隐形延伸防漏**：在 `layout` 测量中向底部延伸 `32.dp`，同时在卡片内部施加 `padding(bottom = 32.dp)`，物理层面消除过冲露底。 | `NemoPageBottomSheet.kt`<br>`Modifier.layout`<br>`Spring` | **动效容差物理补偿公理**：所有带惯性或弹簧的覆盖层边界必须具备尺寸级容差延伸，彻底杜绝运动矢量瞬间露底。 |
| **4. 顶栏非对称按钮导致的标题视觉偏心**<br>顶栏若仅有左侧返回按钮而右侧为空，常规 `Row` 居中会导致标题被左侧按钮挤向右侧，失去秩序感。 | **双侧最大宽度平衡测量算法**：采用自定义 `Layout` 计算 `maxSideWidth = maxOf(leadingWidth, trailingWidth)`，对称预留安全边距并将标题强制置于绝对几何中心。 | `NemoSheetTopBar.kt`<br>`Modifier.layoutId`<br>`fastCoerceAtLeast` | **标题绝对水平居中公理**：模态全屏与抽屉顶栏主标题必须在整个视口物理宽度中绝对居中，严禁受两侧按钮宽度差异影响。 |
| **5. 抽屉项选中即销毁导致的生硬跳变**<br>用户点击列表项选中发音人后，若直接修改外部状态将弹窗销毁，用户无法感知抽屉向下滑出的自然惯性。 | **闭包先滑出再注销时序**：由容器向内容暴露 `slideOut: () -> Unit` 闭包函数，子项点击后先触发 `slideOut()` 协程滑出，再由其在完成时回调 `onDismissed()`。 | `NemoPageBottomSheet.kt`<br>`VoiceSelectionRowItem`<br>`SettingsComponents.kt` | **交互动效完整时序公理**：任何由内容主动触发关闭的交互，必须保持入场与退场的动效物理对称性，杜绝生硬闪断。 |
| **6. 弹窗内液态玻璃按钮无折射变普通半透底色（Backdrop 采样断链）**<br>`FrostedLiquidGlassButton` 若未传入 `backdrop` 或底层滚动列表未挂载采样修饰符，组件将自动退化为普通半透色块，失去透镜形变与高斯模糊。 | **弹窗作用域采样闭环**：在弹窗顶层创建 `val sheetBackdrop = rememberLayerBackdrop()`，底层 `LazyColumn` 挂载 `.layerBackdrop(sheetBackdrop)`，并将其作为 `backdrop` 传入顶栏 `NemoSheetTopBar`。 | `SettingsComponents.kt`<br>`ChineseVoiceSelectionBottomSheet.kt`<br>`NemoSheetTopBar.kt`<br>`rememberLayerBackdrop` | **液态玻璃光学闭环公理**：液态玻璃折射必须由同一层级下的底层内容被采样容器（`.layerBackdrop`）与上层采样透镜（`backdrop` 参数）构成显式数据流闭环。 |

| **8. 浅底浮空卡片灰暗与软阴影裁剪顺序倒置**<br>未选中卡片使用中性浅灰导致与抽屉底色对比度不足；修饰符若先 `.clip(shape)` 再 `.softCardShadow` 会导致弥散阴影被裁断。 | **纯色块明度反差与先阴影后裁剪顺位**：浅色模式未选中底色设为绝对纯白 `Color.White`，深色设为 `#1C1C1E`；修饰符必须为 `softCardShadow` 处于 `clip` 之前，实现完整 16dp 环境漫反射。 | `VoiceSelectionCardItem`<br>`softCardShadow`<br>`Dynamic_Color_System_Spec.md` | **纯白卡片明度反差与修饰符拓扑顺位公理**：浮空卡片在浅色底上必须采用 100% 纯白实现纯净对比；弥散阴影必须优先于图形裁剪，杜绝边缘投影破裂。 |
| **9. 开关无触觉反馈致使手势交互空洞死板**<br>全工程开关仅具备视觉位移动效，缺乏物理拟物阻尼感；直接调用长震动又会导致手感粗糙烦躁。 | **状态实质翻转驱动轻触觉微震**：选用 `HapticFeedbackType.TextHandleMove` 清脆轻触感；在点击与拖拽吸附松手时，仅在状态发生实质变更时（`finalSelected != currentSelected()`）触发微震，拖拽回弹原位不误震。 | `LiquidToggle.kt`<br>`NemoGooeyToggle.kt`<br>`LocalHapticFeedback`<br>`TextHandleMove` | **状态翻转闭环与轻量触觉拟物公理**：开关交互触感必须与状态改变事件严格 1:1 绑定；震感必须克制微弱，模拟物理开关落位的清脆回弹。 |

## 落地架构与设计范式

### 1. 通用抽屉组件结构 (`core:ui`)
```
NemoPageBottomSheet (Box 全屏遮罩 + 下沉抽屉卡片)
 ├── PageSheetScrim (45% 纯黑半透明渐变遮罩，点击拦截退场)
 ├── BackHandler (系统返回手势拦截退场)
 └── Drawer Card (36dp G2 真机硬件连续曲率 + 32dp 延伸防漏)
      ├── Content (支持传入 slideOut 闭包)
      └── NemoSheetTopBar (48dp 高度，标题绝对居中，大圆角返回键)
```

### 2. 语音参数界面独立多彩卡片流排版 (`feature:settings`)
```kotlin
NemoPageBottomSheet(onDismissed = onDismiss) { slideOut ->
    val sheetBackdrop = rememberLayerBackdrop()
    Box(modifier = Modifier.fillMaxSize()) {
        LazyColumn(
            modifier = Modifier.fillMaxSize().layerBackdrop(sheetBackdrop),
            contentPadding = PaddingValues(top = 72.dp, bottom = navBarBottom + 24.dp)
        ) {
            groupedVoices.forEach { (groupName, groupVoices) ->
                item(key = groupName) {
                    SettingsSectionTitle("$groupName (${groupVoices.size})")
                }
                // 彻底移除 PremiumCard，平铺为独立 VoiceSelectionCardItem 浮空微卡片
                itemsIndexed(groupVoices, key = { _, voice -> voice.name }) { index, voice ->
                    val itemColor = VoicePalette.getVoiceColor(voice.name, index, isDark)
                    VoiceSelectionCardItem(
                        displayInfo = formatVoiceName(voice, ...),
                        isSelected = voice.name == currentVoiceName,
                        isPreviewing = previewingVoiceName == voice.name,
                        color = itemColor,
                        onClick = { ...; slideOut() },
                        onPreviewClick = { onPreviewVoice(voice.name) }
                    )
                }
            }
        }
        // 浮动顶栏注入 GPU 光学采样
        NemoSheetTopBar(title = "选择日语发音", onBack = slideOut, backdrop = sheetBackdrop)
    }
}
```
