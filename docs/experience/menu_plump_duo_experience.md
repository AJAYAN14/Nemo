# 经验总结：Menu 菜单界面 Plump Duo 与等亮度调色板改造

| 坑是什么 | 怎么避 | 相关工具/文件 | 统一原则 |
| :--- | :--- | :--- | :--- |
| **1. 菜单右侧选中对勾/折角箭头易被随主色染色** | 在 `NemoMenuItem` 与 `NemoMorphMenuItem` 中，尾部辅助指示控件（`trailingIcon`）原先直接继承了 `leadingIcon` 的 `iconTint`，导致对勾被错误染成彩色。改造时必须显式为 `trailingIcon` 绑定中性灰色 `MaterialTheme.colorScheme.onSurfaceVariant`。 | [`NemoMenu.kt`](file:///e:/Android/Nemo/core/ui/src/main/java/com/jian/nemo/core/ui/component/common/NemoMenu.kt), [`NemoMorphMenu.kt`](file:///e:/Android/Nemo/core/ui/src/main/java/com/jian/nemo/core/ui/component/common/NemoMorphMenu.kt) | 辅助指示箭头、打勾等中性控件一律保持中性色（`onSurfaceVariant`），严格禁止滥用彩色。 |
| **2. 菜单内小图标尺寸容易被误放大至 28~30dp 导致文字挤压** | 菜单项（`NemoMorphMenuItem`）高度紧凑（约 44dp），若盲目套用常规入口的 `28.dp`~`30.dp`，会严重挤占水平间距并导致标题文字换行。必须严格遵守紧凑型尺寸规范，限制绘制尺寸为 `20.dp`。 | [`NemoMenu.kt`](file:///e:/Android/Nemo/core/ui/src/main/java/com/jian/nemo/core/ui/component/common/NemoMenu.kt), [`NemoMorphMenu.kt`](file:///e:/Android/Nemo/core/ui/src/main/java/com/jian/nemo/core/ui/component/common/NemoMorphMenu.kt) | 紧凑型场景与列表菜单项严格尊重尺寸约束（保持 20dp 居中），严禁无脑拉大破坏排版。 |
| **3. 容易将内嵌的开关按钮（Switch / LiquidToggle）误做等亮度染色** | 开关按钮（如 `Switch`、`LiquidToggle`）属于系统基础控件，其激活与关闭态色彩必须严格保持默认方案（`MaterialTheme.colorScheme.primary`），绝对严禁随 Plump Duo 方案进行等亮度染色或改变原有色彩。 | [`LearningCommonComponents.kt`](file:///e:/Android/Nemo/feature/learning/src/main/java/com/jian/nemo/feature/learning/presentation/components/common/LearningCommonComponents.kt) | 开关控件保色铁律：开关按钮严禁跟随 Plump Duo 改动颜色，必须 100% 保持默认系统配色。 |
| **4. 顶部操作栏（AppBar）上的 Menu 触发按钮被误套用彩色** | 菜单触发按钮（如 `MoreVert`、`FrostedLiquidGlassButton`）属于系统级 Navigation Chrome。规范最高红线明确严禁在顶部栏套用 PlumpDuoIcon 或彩色。触发按钮必须严格保持纯单色 Material 图标质感。 | [`TestHeader.kt`](file:///e:/Android/Nemo/feature/test/src/main/java/com/jian/nemo/feature/test/components/TestHeader.kt), [`CollectionActionMenu.kt`](file:///e:/Android/Nemo/feature/collection/src/main/java/com/jian/nemo/feature/collection/components/CollectionActionMenu.kt) | AppBar 顶部操作栏图标绝对禁止 Plump Duo 化与彩色化，保持克制纯净的系统导航质感。 |
| **5. 缺少特定通用业务图标（如暂停 Pause）时从外部异构引入** | 缺少暂停图标时，必须严格从 Lucide 官方原生矢量库（`E:\GitHub\lucide\icons\pause.svg`）提取 24×24 原生网格圆角矩形，并在 `PlumpDuoIcon.kt` 与分片注册表中标准注册，严禁使用外部异构图形破坏风格一致性。 | [`PlumpDuoIcon.kt`](file:///e:/Android/Nemo/core/designsystem/src/main/java/com/jian/nemo/core/designsystem/icon/PlumpDuoIcon.kt), [`PlumpIconsSettings.kt`](file:///e:/Android/Nemo/core/designsystem/src/main/java/com/jian/nemo/core/designsystem/icon/PlumpIconsSettings.kt) | 矢量图形唯一数据来源为本地 Lucide 官方原生库，保证 24×24 网格与 2.1dp 圆角描边一致性。 |
