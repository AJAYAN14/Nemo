# 31-顶栏液态菜单原生光学配方对齐与流体拓扑完整性避坑指南

> 记录 Nemo 项目在统一顶栏双端液态玻璃视觉质感过程中，避免外部 Compose 按钮强行覆盖切断流体连续拉伸动效，通过原生 Shader 光学配方（`GlassRecipe.ControlDark/Light`）在深浅模式下精准对齐底色与微光的架构复盘与避坑实践。

## 核心避坑复盘对照表

| :--- | :--- | :--- | :--- |
| **外部 Compose 按钮包裹导致原生流体拉伸动画断层**：试图用 Compose 的 `FrostedLiquidGlassButton` 在外部包裹并关闭原生玻璃（`glass = false`），导致着色器的 `state.hasSource` 被强行切断为 `false`，按钮与菜单面板之间的水滴流体粘连拓扑被破坏，展开动效丢失连续拉伸感，且上层静态图标破坏了水平三点的展开淡出 | **严守原生流体几何拓扑完整性**：<br>1. 坚决保留原生 `NemoGlassMenuView` 完整的流体渲染管线与图标录制机制（`anchor.glass = true`）；<br>2. 严禁使用外部静态 Compose 按钮强行覆写原生触发器，确保水滴拉丝（Fluid Gooey Morphing）与水平小圆点缩放模糊淡出 100% 连贯 | `GlassMenuSession.kt`<br>`NemoGlassMenuView.kt`<br>`NemoLiquidMenu.kt` | **流体几何拓扑不可分割公理**：原生液态菜单的常态按钮（Source Lobe）与展开面板（Target Menu）在 Shader 中是一个不可分割的连续流体计算域，严禁以外部独立静态节点割裂拓扑流。 |

## 落地规范与关键代码对比

### 1. 原生光学配方精准校准 (`GlassRecipe.kt`)
```kotlin
internal class GlassRecipe(
    val saturation: Float,
    val black: Float,
    val white: Float,
    val rollOff: Float,
    val fillAlpha: Float,
    val tint: Float = 0f,
    val tintAlpha: Float = 0f
) {
    companion object {
        // 深色常态按钮：黑电平沉降至 0.02f，微调 fillAlpha 至 0.12f，综合视觉 100% 等同于返回按钮的 15% 纯白微光 (Color.White.copy(0.15f))
        val ControlDark = GlassRecipe(1.15f, 0.02f, 1.0f, 0.2f, 0.12f)
        val MenuDark = GlassRecipe(1.3f, 0.125f, 1.125f, 0.65f, 0f, tint = 0.042f, tintAlpha = 0.7f)

        // 浅色常态按钮：黑电平彻底降至 0.05f（根除 40% 死灰），微调 fillAlpha 至 0.24f，综合视觉 100% 等同于返回按钮的 30% 温润轻磨砂 (Color.White.copy(0.30f))
        val ControlLight = GlassRecipe(1.15f, 0.05f, 1.0f, 0f, 0.24f)
        val MenuLight = GlassRecipe(1.2f, 0.4f, 1.03f, 0f, 0.2f, tint = 0.975f, tintAlpha = 0.5f)
    }
}
```
