# 学习界面顶栏液态玻璃按钮光学参数与胶囊高光重构避坑指南

> 本文档记录在学习界面（单词与语法学习）顶栏中，消除液态玻璃按钮破坏性色散重影、解决横向胶囊药丸白雾塑料感，以及弥补静态单卡无滚动采样空洞的物理光学渲染经验与工程避坑原则。

| :--- | :--- | :--- | :--- | :--- |
| **坑 1：全局开启色散导致小字号文本重影发虚**<br>在包含文字的 `FrostedLiquidGlassButton` 上开启 `chromaticAberration = true`，导致着色器对 RGB 三色通道做空间位移拆分，使小字号文本（如“剩余: XX”）与图标边缘产生红青彩虹重影，视觉失焦。 | **文字与功能图标按钮彻底关闭色散**：<br>在所有包含文字排版（如胶囊按钮）及标准系统返回/撤销图标的顶栏按钮中，统一显式指定 `chromaticAberration = false`，对齐热力图标杆的纯净清透画风。 | `LearningCommonComponents.kt`<br>`CommonHeader.kt`<br>`FrostedLiquidGlassButton` | **无杂色纯净光学原则**<br>严禁在承载精细文字与功能性图标的液态玻璃按钮上开启强色散，保障字符轮廓的最高纯净度与易读性。 |
| **坑 2：横向拉伸胶囊大面积 30% 纯白底色暴露为塑料膏药**<br>正圆按钮面积小（~1800dp²），30% 白底仅为温润微光；但当胶囊横向展开（~4000dp²）且无高光描边时，30% 纯白底色泛滥成灾，在单一背景上像一块生硬的白色塑料贴纸。 | **0.6dp 晶体拟态高光描边 + 底色大幅轻量化**：<br>1. 引入 0.6dp 垂直渐变微光描边（浅色上白 0.85f -> 下微暗 0.05f，深色上白 0.35f -> 透明），赋予边缘晶体倒角切面反光；<br>2. 将表面底色透明度压降至 8%（深色）/ 15%（浅色），绑定 G2 连续平滑曲率 `Capsule()`。 | `LearningCommonComponents.kt`<br>`Capsule.kt`<br>`Brush.verticalGradient` | **高光锁边与克制底色公理**<br>非正圆大面积液态玻璃元件必须压低表面实色覆盖率，依托 0.6dp 微光渐变描边锁紧边缘立体切面。 |

## 二、 落地规范与关键代码对比

### 1. 胶囊液态玻璃微光描边与参数收敛
```kotlin
// 0.6dp 顶部拟态微光渐变描边（上亮下透，呈现晶体玻璃倒角反光切面）
val capsuleBorderBrush = Brush.verticalGradient(
    colors = if (isDarkTheme) {
        listOf(
            Color.White.copy(alpha = 0.35f),
            Color.White.copy(alpha = 0.12f),
            Color.Transparent
        )
    } else {
        listOf(
            Color.White.copy(alpha = 0.85f),
            Color.White.copy(alpha = 0.30f),
            Color.Black.copy(alpha = 0.05f)
        )
    }
)
val capsuleSurfaceColor = if (isDarkTheme) {
    Color.White.copy(alpha = 0.08f)
} else {
    Color.White.copy(alpha = 0.15f)
}

// 胶囊组件规范调用
FrostedLiquidGlassButton(
    onClick = { ... },
    shape = Capsule(), // G2 连续平滑曲率胶囊
    border = BorderStroke(0.6.dp, capsuleBorderBrush), // 0.6dp 高光锁边
    surfaceColor = capsuleSurfaceColor, // 消除厚重白雾
    backdrop = backdrop,
    hasLens = true,
    chromaticAberration = false, // 彻底消除小字号彩虹重影
    contentPadding = PaddingValues(horizontal = 16.dp, vertical = 0.dp),
    isInteractive = true,
    modifier = Modifier.height(48.dp)
) { ... }
```

### 2. 底层采样图层微光激发
```kotlin
Box(
    modifier = Modifier
        .fillMaxSize()
        .layerBackdrop(learningBackdrop)
) {
    // 顶部氛围微光光晕（贯穿系统状态栏，使 Backdrop 采样具备真实色彩与明度梯度，激发液态玻璃折射）
    Box(
        modifier = Modifier
            .fillMaxWidth()
            .height(statusBarTop + 88.dp)
            .background(
                Brush.verticalGradient(
                    colors = listOf(
                        MaterialTheme.colorScheme.primary.copy(alpha = if (isDarkTheme) 0.12f else 0.08f),
                        MaterialTheme.colorScheme.primary.copy(alpha = if (isDarkTheme) 0.04f else 0.02f),
                        Color.Transparent
                    )
                )
            )
    )
    ...
}
```
