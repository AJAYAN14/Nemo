# 通用更新弹窗居中重构与双层反色胶囊进度条避坑指南

> 记录 Nemo 应用版本更新弹窗从传统抽屉（BottomSheet）向高质感居中弹窗（Dialog）重构，日志自适应高度约束（Min/Max Height）以及按钮原地平滑演进为胶囊进度条（Capsule Morphing Progress）的双层反色裁剪技术经验。

---

## 核心经验对照表

| 坑是什么 | 怎么避 | 相关工具 / 文件 | 统一原则 |
| :--- | :--- | :--- | :--- |
| **居中弹窗长日志撑爆屏幕与短内容扁平干瘪** | 使用 `Modifier.heightIn(min = 96.dp, max = 220.dp)` 双重约束：日志少时保持丰满留白，日志多时 220dp 封顶并自动接管 `verticalScroll`。 | `UpdateDialogContent.kt`, `Modifier.heightIn`, `verticalScroll` | **弹性区间边界公理**：弹窗列表容器必须声明最小保证高度与最大硬顶约束，兼顾美学比例与极端长文本滑动保护。 |
| **单层进度条文字在主色推进过程中色彩冲突看不清** | 采用双层裁剪技术（Dual-layer BoxWithConstraints）：底层显示主题主色文字，顶层随进度条推进宽度使用 `fillMaxWidth(progress).clipToBounds()` 渲染反白文字（`onPrimary`），实现像素级高对比反色。 | `BoxWithConstraints`, `clipToBounds`, `MaterialTheme.colorScheme.primary` | **动态高对比双层反色原则**：变色进度条内嵌文字必须随填充边界进行无缝色相映射，严禁单色硬叠加导致看不清。 |
| **非强制更新下载时误触外部导致任务硬中断或无法后台继续** | 强制更新与可关闭策略解耦：将 `dismissOnClickOutside` 与 `dismissOnBackPress` 严格绑定 `!config.isForce && config.canClose`；弹窗关闭仅注销 UI 展现，下载协程依托 `MainViewModel` 继续在系统通知栏静默流转。 | `UpdateDialog.kt`, `DialogProperties`, `MainViewModel.kt` | **渲染表现与后台任务生命周期解耦原则**：界面浮层的生命周期终结绝不得影响用户已经触发的非阻塞性后台网络与安装流程。 |
| **底层硬件毛玻璃残影与内存泄漏** | 在 `Dialog` 内部通过 `DisposableEffect(view)` 监听生命周期，Android 12+ 启用 `FLAG_BLUR_BEHIND`，退出时显式清理标记并将 `blurBehindRadius` 与 `dimAmount` 归零。 | `DialogWindowProvider`, `FLAG_BLUR_BEHIND`, `DisposableEffect` | **系统硬件资源即用即销公理**：利用系统级 GPU 毛玻璃属性必须建立对称闭环释放机制，防止 Window 泄漏或背景残影。 |
| **高频系统通知 Binder IPC 阻塞主线程导致 Compose 掉帧跳跃至 100%** | 点击时毫秒级切入下载态消除响应空窗；通知栏做时间与阈值节流（至少 500ms 或 5% 才发出 notify），UI 进度采用低刚度物理弹簧阻尼平滑插值。 | `MainViewModel.kt`, `NotificationHelper`, `spring` | **跨进程节流与渲染流体平滑原则**：高频数据流必须在业务层对昂贵系统 IPC 执行降频削峰，保障主线程 UI 渲染管线 60/120fps 平稳调度。 |

## 关键技术实现要点

1. **G2 平滑连续曲率与深浅色阶梯自适应**：
   - 弹窗采用 `RoundedRectangle(40.dp)` 容器，深度契合 Nemo 极简美学；
   - 深色模式采用 `UiPalette.DialogAltDarkBg`，浅色模式采用纯白加 `16.dp` 柔光阴影与细腻微光边框。
2. **按钮形态演进（Button Morphing）**：
   - 初始态：建议更新呈现双胶囊按钮，强制更新呈现居中单胶囊按钮；
   - 下载态：双按钮平滑合体为 `52.dp` 全宽胶囊进度条，内嵌平滑动画进度 `animatedProgress`；
   - 完成态：原地转变为单个“立即安装”主色胶囊按钮。
3. **主线程 IPC 节流与物理弹簧**：
   - 避免每 1% 进度重复触发 `NotificationManagerCompat.notify()` 造成严重主线程卡顿；
   - 采用 `Spring.DampingRatioNoBouncy` 搭配 `Spring.StiffnessLow`，消除任何突兀瞬变感。
