# 经验总结：统计界面 Plump Duo 与等亮度调色板改造

| :--- | :--- | :--- | :--- |
| **1. 展开按钮辅助箭头与指示器易被误套用彩色** | 严格区分“功能性强调色”与“辅助性中性指示器”。当 `isPlumpDuo` 为 true 时，箭头（如 `KeyboardArrowDown`/`KeyboardArrowUp`）强制使用 `MaterialTheme.colorScheme.onSurfaceVariant`，禁止滥用彩色。 | [`StatisticsScreen.kt`](file:///C:/Users/AJIAN14/.gemini/antigravity/worktrees/Nemo/add_plump_duo_icon_style/feature/statistics/src/main/java/com/jian/nemo/feature/statistics/StatisticsScreen.kt) | 辅助指示箭头、清除按钮等中性控件一律保持中性色（`onSurfaceVariant`），防止界面色彩过载。 |

| **3. 忽视列表项内动态多彩头像与级别阶梯色** | 单词列表和统计列表常有循环多彩头像（如 `AvatarColors`），改造时需提供一套基于 `IsoluminantPalette` 的感知均匀 8 色环（`PlumpAvatarColors`），使头像大字亮度均衡；级别标签如果原有是中性灰则保留，彩色阶梯则切换至等亮度色。 | [`StatisticsScreen.kt`](file:///C:/Users/AJIAN14/.gemini/antigravity/worktrees/Nemo/add_plump_duo_icon_style/feature/statistics/src/main/java/com/jian/nemo/feature/statistics/StatisticsScreen.kt), [`LevelBreakdownDialog.kt`](file:///C:/Users/AJIAN14/.gemini/antigravity/worktrees/Nemo/add_plump_duo_icon_style/feature/statistics/src/main/java/com/jian/nemo/feature/statistics/components/LevelBreakdownDialog.kt) | 全界面色彩协同：不能只换图标不换界面强调色，所有彩色元素同步切换为等亮度 OKLCH 体系。 |
| **4. 新 worktree 缺少 gitignore 文件导致编译依赖报错** | Worktree 初始缺失被忽略的 `gradle.properties`（如 `android.useAndroidX=true`），会导致 AndroidX 依赖解析报错；需从主工程目录同步拷贝基础构建属性。 | `gradle.properties` | 验证多模块构建前确认工作区构建配置完整无缺。 |
| **5. IsoluminantPalette 包路径易错引为 theme** | `IsoluminantPalette` 统一归属于 `com.jian.nemo.core.designsystem.icon.IsoluminantPalette` 而非 `theme` 包。引错会导致 `compileDebugKotlin` 报 `Unresolved reference`。 | [`ForgettingCurveChart.kt`](file:///e:/Android/Nemo/feature/statistics/src/main/java/com/jian/nemo/feature/statistics/presentation/curve/components/ForgettingCurveChart.kt) | 引用等亮度调色板必须对齐 `core.designsystem.icon.IsoluminantPalette` 统一定义。 |
| **6. 折线图高度硬编码过大导致底部诊断卡片出屏** | 遗忘曲线等仪表盘图表若硬编码 `.height(600.dp)`，在竖屏设备上会挤占整个视口，导致下方的“三元记忆警戒推演卡片”被完全挤出屏幕。必须将图表高度调整为紧凑的 `300.dp`。 | [`ForgettingCurveChart.kt`](file:///e:/Android/Nemo/feature/statistics/src/main/java/com/jian/nemo/feature/statistics/presentation/curve/components/ForgettingCurveChart.kt) | 仪表盘折线图高度保持在 280~320dp 黄金比例，确保分段器、图表与诊断卡片一屏尽收眼底。 |
| **7. 空状态图标外套实色方块底框产生贴纸感** | 复学清单等界面在空状态图标外部若硬套 `Surface(modifier = Modifier.size(100.dp), shape = RoundedCornerShape(32.dp))`，严重违反规范指南第二章第 1 铁律。在 `isPlumpDuo` 方案下必须彻底剥离外层背景框，直接使用 `PlumpDuoIcon` 居中通透展示。 | [`LeechManagementScreen.kt`](file:///e:/Android/Nemo/feature/statistics/src/main/java/com/jian/nemo/feature/statistics/presentation/dashboard/LeechManagementScreen.kt) | 严禁在 Plump Duo 图标外部套用厚重纯色方块/圆角底色，图标自身已具备双层立体软底。 |
| **8. PlumpDuoIcon 参数名为 color 且 SettingIconStyle 归属 domain** | `PlumpDuoIcon` 接收的颜色形参为 `color: Color`（并非 Icon 组件惯用的 `tint`）；`SettingIconStyle` 归属于 `com.jian.nemo.core.domain.repository.SettingIconStyle`。 | [`AbilityWorkshopScreen.kt`](file:///e:/Android/Nemo/feature/test/src/main/java/com/jian/nemo/feature/test/presentation/ability/AbilityWorkshopScreen.kt) | 调用 PlumpDuoIcon 统一显式使用 `color = ...`，导入 SettingIconStyle 统一对齐 domain 仓库层。 |
