# 输入框调色盘收敛与 G2 连续曲率圆角落地经验

> 本文档记录 Nemo 全项目所有输入框（TextField、OutlinedTextField、BasicTextField、搜索栏等）在推进颜色收纳至 `docs/` 设计规范调色盘、深浅模式明度阶梯对齐、以及全量统一 G2 平滑连续曲率（`RoundedRectangle`）过程中的关键避坑经验。

---

## 核心避坑对照表 (四列格式)

| 坑是什么 (Problem) | 怎么避 (Workaround / Solution) | 相关工具 / 文件 | 统一原则 (Design Axiom) |
| :--- | :--- | :--- | :--- |
| **输入框硬编码非标色值与 Tailwind 历史残留**<br>历史代码在举报弹窗（`ContentReportDialog`）中散落使用了 `ReportZinc800/100/700` 等非标 Tailwind 色彩；在发现栏（`DiscoveryBar`）中直接硬编码 `Color.Black`，导致深色模式下出现黑字黑光标看不清的问题。 | **全面收敛至 MaterialTheme 语义槽位与深浅自适应色盘**：将输入框底色、边框、光标与占位符映射至 `MaterialTheme.colorScheme.surfaceContainerHigh / surfaceVariant`、`primary`、`outline` 与 `onSurfaceVariant`；发现栏判断 `isDark` 动态切换白/黑字，占位符对齐 35% 白高对比度。 | `ContentReportDialog.kt`<br>`DiscoveryBar.kt`<br>`LoginComponents.kt`<br>`RegisterCaptchaDialog.kt` | **语义化槽位映射优先公理**：全项目 Composable 界面输入框颜色优先映射 `MaterialTheme.colorScheme.*`，由主题引擎统一分发深浅色；严禁私自声明非标 Tailwind 颜色或在输入框写死黑白字。 |
| **输入框遗漏 shape 参数导致降级为非 G2 圆角**<br>搜索框与通用列表页面（`GenericExpandableListScreen`）中使用的 `OutlinedTextField` 遗漏了 `shape` 属性设置，导致直接退化为 MD3 默认普通切角圆弧，破坏了全应用统一的 iOS / 苹果极简 G2 连续曲率秩序感。 | **显式绑定 G2 连续曲率平滑圆角**：为所有输入框显式指定 `shape = RoundedRectangle(12.dp)`（大搜索框 / 主输入框使用 12dp~16dp 阶梯）；全项目 16 个输入框组件文件经过端到端核验，确保 100% 覆盖 G2 平滑连续曲率。 | `GenericExpandableListScreen.kt`<br>`RoundedRectangle.kt`<br>`AIModelStudioComponents.kt` | **G2 平滑连续曲率公理**：全应用所有带边框与容器外观的输入控件，必须显式绑定 `RoundedRectangle`，严禁使用系统默认 `RoundedCornerShape` 或遗漏 shape 参数。 |
| **跨模块引用顶层非导出符号与 Gradle ABI 缓存陷阱**<br>在跨模块引用 `:core:designsystem` 中的颜色时，若直接使用未通过 object 导出的 top-level 颜色变量，在多模块增量编译或 Daemon 缓存不一致时易导致 `Unresolved reference` 编译中断。 | **遵循色值映射优先级并采用 Object 安全导出**：界面代码严格遵照 `rules-ui-fidelity.md` 第 1 优先级——直接消费 `MaterialTheme.colorScheme`；跨模块专属色板统一通过 `object` 单例（如 `IosColors`、`UiPalette`、`StudioThemePalette`）显式调用，杜绝散装全局变量依赖。 | `AIModelStudioComponents.kt`<br>`Color.kt`<br>`rules-ui-fidelity.md` | **色彩调用层级公理**：1 级用 `MaterialTheme.colorScheme` 语义色；2 级用 `IosColors` 专属物理色；跨模块复用必须使用单例 object 封装，杜绝裸符号依赖。 |
| **填空格子与步进器强调色缺失暗黑模式光学补偿**<br>单词填空（`WordClozeScreen`）激活框、光标与数字步进器（`PremiumStepper`）在深浅模式下共用同一硬编码橙色（`#FF5500` / `#FF9500`），在深色背景下因明度不足产生暗沉沉闷感。 | **引入深浅色阶动态光学补偿**：浅色模式选用活力柔和的 `IosColors.Orange`（`#FF9500`），深色模式自动自发光补偿选用 `IosColors.OrangeDark`（`#FF9F0A`）；步进器 `accentColor` 默认置为 `Color.Unspecified`，在 Composable 内部自适应深浅亮度阶梯。 | `PremiumStepper.kt`<br>`WordClozeScreen.kt`<br>`IosColors.kt` | **深浅光学明度补偿原则**：强调色（Accent / Brand Color）在深色背景下必须选用自发光色阶（如 `OrangeDark`），保障无障碍对比度与生动的视觉张力。 |

## 落地规范检查台账

1. **输入框圆角规范**：
   - 搜索框（`GenericExpandableListScreen` / `SearchTopBar`）：`RoundedRectangle(12.dp)`
   - 表单输入框（`LoginComponents` / `RegisterCaptchaDialog` / `AISettingsScreen`）：`RoundedRectangle(14.dp)`
   - 极客代码与高级模型卡槽（`AIModelStudioComponents` / `SlotModelPicker`）：`RoundedRectangle(16.dp)`
   - 填空格子（`WordClozeScreen`）：`RoundedRectangle(12.dp)`
   - 数字步进器（`PremiumStepper`）：`RoundedRectangle(16.dp)`
   - **全项目 G2 连续平滑曲率覆盖率**：**100%**
2. **调色盘与语义化规范**：
   - 背景容器：`MaterialTheme.colorScheme.surface` / `surfaceVariant` / `surfaceContainerHigh`（深浅自适应）
   - 边框描边：聚焦 `primary` / 品牌色，未聚焦 `outline`（`Color(0xFFE5E5EA)` / 深色 `Color(0xFF38383A)`）
   - 输入文本：`MaterialTheme.colorScheme.onSurface`
   - 占位提示：`MaterialTheme.colorScheme.onSurfaceVariant.copy(alpha = 0.6f)`
   - 强调与光标：`IosColors.Orange` / `IosColors.OrangeDark` 自发光光学补偿
3. **构建质量**：
   - 全工程 `compileDebugKotlin` 0 错误构建通过（BUILD SUCCESSFUL）。
