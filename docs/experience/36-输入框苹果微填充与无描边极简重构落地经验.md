# 输入框苹果微填充与无描边极简重构落地经验

> 本文档记录 Nemo 全项目在推行苹果原生极简输入框（`tertiarySystemFill` 动态半透明微填充）、彻底消除未聚焦/聚焦外圈静态描边（无边框色块）、保留错误告警描边、以及严守 7 类特殊输入框白名单过程中的核心避坑经验。

---

## 核心避坑对照表 (四列格式)

| 坑是什么 (Problem) | 怎么避 (Workaround / Solution) | 相关工具 / 文件 | 统一原则 (Design Axiom) |
| :--- | :--- | :--- | :--- |
| **输入框硬编码白色/灰色实色底导致在深浅多层嵌套卡片中割裂突兀**<br>历史代码散落在各个业务页面中写死 `if (isDark) surfaceContainerHigh else Color.White` 或 `surface`，导致嵌在白卡片内与直接置于底色画布上明度反差失衡，无法自适应父容器材质。 | **收敛至苹果官方动态微透填充 Token**：在 `:core:designsystem` 的 `Color.kt` 中声明 `NemoInputFillLight` (`#1F787880` 12% 动态灰) 与 `NemoInputFillDark` (`#3D787880` 24% 动态灰)，利用半透明微凹质感自适应任何宿主容器底色。 | `Color.kt`<br>`NemoTextFieldDefaults.kt`<br>`LoginComponents.kt`<br>`AISettingsScreen.kt` | **环境自适应微凹填充公理**：全应用通用输入框统一采用苹果原生 `tertiarySystemFill` 动态微填充，禁止硬编码实色白底或死灰底。 |
| **输入框默认带灰色静态描边线条破坏苹果极简视觉纯粹感**<br>Material3 `OutlinedTextField` 默认带有 1dp 轮廓描边（`outline` / `outlineVariant`），在输入框已经具备微凹色块的情况下，额外的灰色线框造成视觉噪音与沉重感。 | **消除常规与聚焦外圈描边，仅保留错误态红线指示**：在 `NemoTextFieldDefaults.colors()` 中将 `unfocusedBorderColor` 与 `focusedBorderColor` 均置为 `Color.Transparent`，光标使用品牌色；唯一保留 `errorBorderColor = MaterialTheme.colorScheme.error` 保障表单报错校验可用性。 | `NemoTextFieldDefaults.kt`<br>`GenericExpandableListScreen.kt`<br>`ContentReportDialog.kt` | **无描边纯色块交互公理**：通用输入框常规态与聚焦态一律无外圈描边（Transparent），聚焦纯靠光标闪烁，禁止绘制僵硬轮廓线。 |
| **一刀切全量改造导致液态材质被遮挡、题干挖空排版割裂**<br>若教条式将所有 `TextField` 组件一网打尽，会导致 `DiscoveryBar` 的 AGSL 液态磨砂折射被灰色遮挡，导致完形填空 `WordClozeScreen` 题干中文字流动被方块截断，导致 `PremiumStepper` 产生胶囊套娃。 | **确立白名单豁免机制严格防篡改**：明确划定 7 类特殊交互白名单（`DiscoveryBar` 透明底、`WordClozeScreen` 流动下划线、`PremiumStepper` 内部透明、`AIModelStudioComponents` 极客终端卡槽、`TypingTestContent` 正误双态反馈、`TypingPracticeDialog`、`AIReadingScreen` 只读渲染器），严禁改动。 | `DiscoveryBar.kt`<br>`WordClozeScreen.kt`<br>`PremiumStepper.kt`<br>`AIModelStudioComponents.kt` | **白名单神圣不可侵犯原则**：非通用表单类的特殊材质容器与游戏化答题控件，一律列入白名单豁免，严禁教条化一刀切覆盖。 |
| **分散配置 OutlinedTextFieldDefaults 导致未来维护再次分裂**<br>各业务页面各自书写长串的 colors 属性，一旦要微调光标、占位符或边框参数，需要全项目多处联动修改，极易遗漏。 | **建立公共组件规范级工厂 NemoTextFieldDefaults**：在 `:core:ui` 中封装单一真理源（Single Source of Truth），业务页面一律调用 `colors = NemoTextFieldDefaults.colors()`，实现一处定义、全端收纳。 | `NemoTextFieldDefaults.kt` | **单一真理源公理**：高频公共控件的视觉配置必须在核心 UI 模块中抽象出 Defaults 工厂，杜绝业务端散落式配置。 |

| **业务页面重复配置 shape 与 colors 模板代码繁琐**<br>每次调用 `OutlinedTextField` 都要显式传入 `shape = RoundedRectangle(14.dp)` 与 `colors = NemoTextFieldDefaults.colors()`，不仅模板代码冗长，而且容易疏漏。 | **封装开箱即用通用组件 NemoTextField**：在 `:core:ui` 封装 `NemoTextField`，将 G2 连续平滑曲率与苹果微透无描边设为默认参数，业务方直接调用即可，大幅降低接入心智负担。 | `NemoTextField.kt`<br>`GenericExpandableListScreen.kt`<br>`ExpressionScreen.kt` | **开箱即用高阶封装公理**：设计系统的高频标准组件必须提供零样板代码的开箱即用封装，将视觉规范内聚于组件默认行为中。 |
| **部分历史弹窗输入框圆角手写 20dp/26dp 导致方圆比例失衡**<br>账号管理弹窗（`AccountManagementDialogs`）早期手写了 20dp 甚至 26dp 的超大圆角，在 50dp 行高中呈现接近全胶囊的过度弯折，破坏了与全应用标准表单 14dp 的一致性。 | **全面拉齐至标准级 RoundedRectangle(14.dp)**：将账号管理弹窗中全部 8 处输入框（改用户名/改密/邮箱/OTP/注销验证）的圆角统一收拢为标准 14dp G2 平滑曲率。 | `AccountManagementDialogs.kt` | **全局曲率阶梯一致性公理**：全应用标准表单与弹窗输入框统一锁定 14dp G2 连续平滑曲率，杜绝孤岛式自定义超大圆角。 |
| **Outlined 输入框使用浮动标签导致左上角产生生硬色块包裹与切口**<br>在无描边微透灰底色下，`OutlinedTextField` 的 `label` 会上浮跨越输入框顶边（50% 在框外），且系统底层 Cutout 遮罩会把边框挖开并垫上矩形遮罩色块，视觉上形成文字被方形补丁包裹、圆角被硬生生咬掉一块的严重瑕疵。 | **迁移为纯净容器内浮动（Inside Floating Label）**：在 `NemoTextFieldDefaults` 封装 `filledColors()`（去除底线 indicator，应用微透填充），将输入框切为 `TextField` 填充型内浮动机制。标签缩小后平滑收纳在输入框内部正上方，输入文本在下方，总高度保持标准 56dp 且比原先外凸更省 8dp 空间，彻底杜绝色块包裹。 | `NemoTextFieldDefaults.kt`<br>`AccountManagementDialogs.kt` | **纯净内收纳浮动公理**：微填充无描边输入框若采用浮动标签动效，必须将标签完全收纳于内部容器空间（Inside），严禁跨越顶边或产生 Cutout 破口。 |

## 落地规范检查台账

1. **输入框形态与曲率规范**：
   - 通用顶层组件：`NemoTextField` 默认绑定 `RoundedRectangle(14.dp)` 与 `NemoTextFieldDefaults.colors()`
   - 登录/注册表单（`LoginComponents`）：`RoundedRectangle(14.dp)`，G2 连续曲率平滑无描边
   - 账号管理弹窗（`AccountManagementDialogs`）：**全量修正为 `RoundedRectangle(14.dp)` 并接入纯净容器内浮动（`TextField` + `filledColors`）**，彻底消除 20dp/26dp 臃肿胶囊感与左上角色块包裹瑕疵，保持 56dp 标准高且不外凸
   - AI 设置表单（`AISettingsScreen`）：`RoundedRectangle(14.dp)`，G2 连续曲率无描边
   - AI 模型工作室（`AIModelStudioComponents`）：`RoundedRectangle(14.dp / 16.dp)`，苹果微填充与无描边
   - 内容举报描述（`ContentReportDialog` / `NemoTextField`）：`RoundedRectangle(14.dp)`，G2 连续曲率无描边
   - 列表/表达搜索框（`GenericExpandableListScreen` / `ExpressionScreen` 使用 `NemoTextField`）：`RoundedRectangle(12.dp)`，G2 连续曲率无描边
   - AI 创作工坊答题区（`AIWorkshopScreen`）：`RoundedRectangle(20.dp)`，G2 连续曲率无描边
2. **调色盘与描边规范**：
   - 背景容器：浅色 `Color(0x1F787880)` (12% 动态灰) / 深色 `Color(0x3D787880)` (24% 动态灰)
   - 外圈描边：未聚焦 `Color.Transparent` / 聚焦 `Color.Transparent` / 错误态 `MaterialTheme.colorScheme.error`
   - 光标颜色：`MaterialTheme.colorScheme.primary`
   - 文本与占位：主文本 `onSurface`，占位文本 `onSurfaceVariant.copy(alpha = 0.6f)`
3. **白名单保护项**：
   - `DiscoveryBar`、`WordClozeScreen`、`PremiumStepper`、`AIModelStudioComponents`、`TypingTestContent`、`TypingPracticeDialog`、`AIReadingScreen` 保持原状，0 改动。
