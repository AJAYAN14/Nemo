# 学习卡片顶部胶囊组件高度对齐与文本度量避坑指南

> 本文档记录在学习卡片顶部横向并列胶囊布局中，因文本度量与缺失高度约束导致胶囊高低参差不齐的问题剖析、规整方案与工程避坑原则。

---

## 一、 四列核心经验对照表

| 坑是什么（Problem & Root Cause） | 怎么避（Resolution & Practice） | 相关工具 / 文件 | 统一原则（Principle） |
| :--- | :--- | :--- | :--- |
| **坑 1：未显式约束容器高度导致文本度量撑大胶囊**<br>在水平并排胶囊列表中，中间跑道进度指示器显式指定了 `height(28.dp)`，而左右两边的等级与状态徽章仅通过 `padding(horizontal = 14.dp, vertical = 6.dp)` 撑开。在系统默认开启 `includeFontPadding = true` 时，中文字形度量高度达到约 18~20sp，致使实际渲染高度膨胀至 30dp~32dp，在同级 Row 中产生明显的上下边缘错位。 | **显式锁定胶囊容器高度并配置内容居中**：<br>1. 为所有作为胶囊药丸的 `Box` 容器统一添加明确的 `.height(28.dp)` 尺寸约束；<br>2. 容器指定 `contentAlignment = Alignment.Center`，移除垂直方向的手动 padding，改由容器绝对高度做几何对称包裹。 | `SRSLearningCard.kt`<br>`SRSGrammarCard.kt`<br>`TrackProgressIndicator.kt`<br>`Modifier.height` | **容器几何确定性原则**<br>横向并排的同阶胶囊组件必须使用显式统一的高度约束（如 `height(28.dp)`），严禁依靠文字内边距隐式撑开高度。 |
| **坑 2：不同语言字形度量差异导致同一排胶囊高低互异**<br>左侧等级徽章为纯英文字符（如 "N1"），右侧状态徽章为中文字符（如“新学”、“复习”）。英文字符与中文字符在 Android 默认字体引擎下的上下延伸（Ascent/Descent）度量存在显著差异，且受系统字体放大因子（Font Scale）影响，导致没有固定高度时左右两端高低参差。 | **强制关闭字体内置留白偏差**：<br>在徽章内部文本样式中显式配置 `style = TextStyle(platformStyle = PlatformTextStyle(includeFontPadding = false))`，切断系统字体库上下多余的空白度量，确保多语言文字在几何居中容器内绝对对齐。 | `PlatformTextStyle`<br>`TextStyle`<br>`includeFontPadding` | **字形度量中立原则**<br>高精度小胶囊内的排版文本必须关闭 `includeFontPadding`，规避系统多语言字体度量不一致带来的视觉高差污染。 |

## 二、 落地规范与关键代码对比

### 1. 规整前后的胶囊容器对比

```kotlin
// 🔴 错误做法：依靠垂直内边距隐式撑开（受字体度量影响膨胀至 30~32dp，且英中文高低不一）
Box(
    modifier = Modifier
        .background(levelBg, CircleShape)
        .padding(horizontal = 14.dp, vertical = 6.dp)
) {
    Text(
        text = word.level,
        color = levelText,
        fontSize = 12.sp,
        fontWeight = FontWeight.Black,
        letterSpacing = 1.2.sp
    )
}

// 🟢 正确规范：显式锁定 28dp 高度容器 + 几何居中 + 剔除字体内边距
Box(
    modifier = Modifier
        .height(28.dp)
        .background(levelBg, CircleShape)
        .padding(horizontal = 14.dp),
    contentAlignment = Alignment.Center
) {
    Text(
        text = word.level,
        color = levelText,
        fontSize = 12.sp,
        fontWeight = FontWeight.Black,
        letterSpacing = 1.2.sp,
        style = TextStyle(
            platformStyle = PlatformTextStyle(
                includeFontPadding = false
            )
        )
    )
}
```

### 2. 跑道与徽章三位一体平齐对齐标准

在 `Row(verticalAlignment = Alignment.CenterVertically)` 布局中：
- 左侧等级徽章：`height(28.dp)` + `CircleShape` + 水平 `14.dp`
- 中间进度跑道：`height(28.dp)` + `CircleShape` + 宽 `124.dp`
- 右侧状态徽章：`height(28.dp)` + `CircleShape` + 水平 `14.dp`

三者物理高度绝对恒定，彻底杜绝系统字体缩放与语言字形切换导致的界面错位。
