## 二、 悬浮折射顶栏黄金实现范式（标杆代码）

全工程中凡涉及全屏纵向滚动、背景采样折射（Backdrop）与悬浮顶栏的子界面，**后续所有 AI 必须 100% 遵照以下结构实现**：

```kotlin
@Composable
fun StandardSubScreen(
    onNavigateBack: () -> Unit
) {
    val scrollState = rememberScrollState()
    val backdrop = rememberLayerBackdrop()

    // 1. 动态读取系统真实窗口安全边距
    val statusBarTop = WindowInsets.statusBars.asPaddingValues().calculateTopPadding()
    val navBarBottom = WindowInsets.navigationBars.asPaddingValues().calculateBottomPadding()

    val isDark = MaterialTheme.colorScheme.background.luminance() < 0.5f
    val backgroundColor = MaterialTheme.colorScheme.background

    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(backgroundColor)
    ) {
        // 2. 底层滚动内容（被 backdrop 采样源录制，全屏向上贯穿至状态栏）
        Column(
            modifier = Modifier
                .fillMaxSize()
                .layerBackdrop(backdrop)
                .verticalScroll(scrollState)
                .padding(
                    top = statusBarTop + 60.dp + 16.dp, // 核心：严格避让 48dp 顶栏 + 状态栏 + 16dp 呼吸间距
                    bottom = navBarBottom + 24.dp
                )
        ) {
            // 页面卡片与内容...
        }

        // 3. 悬浮固定顶栏（标准四阶垂直渐变遮罩 + 48dp CommonHeader）
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .align(Alignment.TopCenter)
                .background(
                    Brush.verticalGradient(
                        colors = listOf(
                            backgroundColor.copy(alpha = 0.95f),
                            backgroundColor.copy(alpha = 0.75f),
                            backgroundColor.copy(alpha = 0.35f),
                            Color.Transparent
                        )
                    )
                )
                .padding(bottom = 8.dp)
        ) {
            CommonHeader(
                title = stringResource(R.string.your_screen_title),
                onBack = onNavigateBack,
                backgroundColor = Color.Transparent,
                backdrop = backdrop,
                backButtonSize = 48.dp // 规范标准大按钮
            )
        }
    }
}
```

## 三、 对比类几何实验室（G1 vs G2）设计要点

1. **红蓝对比色映射**：
   - 🔴 **G1 标准圆角（参照组）**：浅色 `NemoDanger`（`#FF3B30`）/ 深色 `NemoDangerDark`（`#FF453A`）
   - 🔵 **G2 连续平滑圆角（现代规范组）**：浅色 `NemoPrimary`（`#007AFF`）/ 深色 `NemoPrimaryDark`（`#0A84FF`）
2. **曲率梳（Curvature Comb）可视化**：
   - 当轮廓物理差距微观（仅 1~1.5dp）时，肉眼难以直接察觉；
   - 沿着转折点绘制法线引线：G1 呈矩形断崖跳变，G2 呈光滑钟形渐进过渡。
