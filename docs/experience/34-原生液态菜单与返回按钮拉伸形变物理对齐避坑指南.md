# 原生液态菜单与返回按钮拉伸形变物理对齐避坑指南

> 本文档总结 Nemo 顶栏原生液态菜单（`NemoGlassMenuView` / `GlassJelly`）与经典液态返回按钮（`FrostedLiquidGlassButton` / `InteractiveHighlight`）拉伸形变、阻尼位移与内容锚点对其的物理建模对齐经验。

---

## 1. 核心经验复盘对照表

| 坑是什么 (Pitfall) | 怎么避 (Remediation) | 相关工具 / 文件 | 统一原则 (Guiding Principle) |
| :--- | :--- | :--- | :--- |
| **1. 误引入泊松比挤压导致按钮被压扁变畸形**：Menu 按钮在拖拽拉伸时引入了负向垂直压缩项 `(cosA - 0.35f * sinA)`，导致沿 X 轴拉伸时 Y 轴变薄变扁，破坏了圆润饱满质感。 | **完全对齐返回按钮无压缩拉伸**：返回按钮仅做轴向平方投影正向单轴拉伸，垂直轴保持基础按压膨胀 `scale`（1.0833），绝不做负向干瘪挤压。 | `GlassJelly.kt`, `LiquidGlassButtons.kt` | **物理单向拉伸与几何饱满原则**：流体按钮按压变形应保持水滴张力，非拉伸轴严禁擅自做削薄压缩，维持饱满温润手感。 |
| **2. 位移衰减斜率不一致导致按钮“乱跑飘移”**：Menu 按钮如果中心位移上限过大或分母偏小，用户拖拽时会明显感觉按钮脱离原位乱动，而返回按钮则有稳如泰山的原地微吸附感。 | **严格对齐双曲正切极低位移公式**：采用 $M \cdot \tanh(0.05 \cdot dx / M)$（其中 $M = \min(W, H)$，斜率仅为 $0.05$），拖动 50dp 仅微移 2.49dp，实现“位置不会变、只在原地发生弹性拉伸”的沉稳高级触感。 | `GlassJelly.kt`, `LiquidGlassButtons.kt` | **微位移强吸附原则**：顶栏功能性锚点按钮在拖拽受力时，位移必须经由极高阻尼（95%衰减）微弱钳位，绝不可脱离原位。 |
| **3. 内容 RenderNode 缩放锚点设为 (0,0) 导致图标与外壳错位**：`recordContent()` 中将 Pivot 设为 `(0, 0)`，当毛玻璃外壳以几何中心向四周拉伸时，内部三点图标却从左上角缩放，导致视觉脱节。 | **几何中心双向绝对对齐**：将 `node.setPivotX(w / 2f)`、`node.setPivotY(h / 2f)`，并在绘制时平移至 `state.incoming.centerX() - w / 2f`，确保内部图标与外部毛玻璃以物理中心 100% 严丝合缝同频缩放。 | `NemoGlassMenuView.kt`, `GlassMenuOverlay.kt` | **渲染图层中心绝对重合原则**：复合图层在应用非刚体缩放形变时，所有子图层与着色器几何域的 Pivot 必须在代数与视觉上严格重合。 |
| **4. 极端拖拽距离下拉成长条面条**：线性形变公式在手指滑动跨越大半个屏幕时会导致 scale 无限制线性增长，破坏 UI 结构。 | **大距离平滑软饱和上限**：引入 `dragLimit = 3.5f * longest`，采用 `longest * 3.5f * tanh(dx / dragLimit)`，常规滑动区间 100% 严格贴合线性手感，极大距离平滑收敛在约 29% 最大拉伸上限。 | `GlassJelly.kt` | **软饱和安全裕度原则**：所有基于手势位移的非线性物理动画，必须在极端物理边界处配置一阶连续可微的软饱和阻尼上限。 |

## 2. 核心数学模型实现

```kotlin
// GlassJelly.deformControl 核心数学实现
fun deformControl(out: RectF, density: Float, amount: Float) {
    val width = max(out.width(), 1f)
    val height = max(out.height(), 1f)
    val longest = max(width, height)
    val shortest = min(width, height)
    val dx = dragX.value
    val dy = dragY.value
    val scale = swell(height, density, amount)
    val angle = atan2(dy, dx)

    // 1. 中心位置微锚定（完全对齐返回按钮：initialDerivative = 0.05f，位置稳如泰山）
    val centerX = out.centerX() + shortest * tanh(DragLean * dx / shortest) * amount
    val centerY = out.centerY() + shortest * tanh(DragLean * dy / shortest) * amount

    // 2. 轴向拉伸与缩放（完全对齐返回按钮：极坐标平方投影分解，无负向压扁）
    val maxDragScale = ControlLift * density * amount / height
    val dragLimit = 3.5f * longest
    val effectiveDx = longest * 3.5f * tanh(dx / dragLimit)
    val effectiveDy = longest * 3.5f * tanh(dy / dragLimit)

    val stretchX = maxDragScale * abs(cos(angle) * effectiveDx / longest) * min(width / height, 1f)
    val stretchY = maxDragScale * abs(sin(angle) * effectiveDy / longest) * min(height / width, 1f)

    val scaleX = scale + stretchX
    val scaleY = scale + stretchY

    val halfWidth = width * scaleX / 2f
    val halfHeight = height * scaleY / 2f
    out.set(centerX - halfWidth, centerY - halfHeight, centerX + halfWidth, centerY + halfHeight)
}
```
