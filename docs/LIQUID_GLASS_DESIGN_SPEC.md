# Nemo 液态玻璃视觉与交互设计规范（Liquid Glass Design Spec）

版本：v2.0  
生效版本：Nemo v1.1+  
核心定位：现代灵动、无界通透、原生触感

---

## 1. 核心设计哲学

Nemo 视觉系统由传统的 Material 3 演进至 **Liquid Glass（液态玻璃）与 Ambient Glow（环境弥散光晕）** 体系：
- **通透沉浸（Translucency）**：摒弃生硬的实体边框与高对比实线，采用多层半透明磨砂玻璃材质，使背景与前景光影产生有机交融。
- **同源光晕（Ambient Glow）**：卡片与关键交互控件使用与其自身主色调同源的广域高斯弥散软阴影（`softShadow`），营造悬浮于界面的通透发光质感。
- **触感弹性（Living Interaction）**：采用弹簧物理模型（Spring Spec），交互拖动具备独占手势锁，释放后平滑自然回弹，无机械僵硬感。

## 2. 材质与色阶基线

### 2.1 液态玻璃材质参数
| 材质层级 | 背景色彩定义 (Light) | 背景色彩定义 (Dark) | 模糊度 / 边框 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **Glass Surface Level 1** | `Color.White.copy(alpha = 0.85f)` | `Color(0xFF1E1E1E).copy(alpha = 0.82f)` | 无实线边框，底衬高斯模糊 | 主卡片容器、设置项卡片 |
| **Glass Capsule Level 2** | `Color.White.copy(alpha = 0.65f)` | `Color(0xFF2A2A2A).copy(alpha = 0.60f)` | 圆角胶囊，`alpha = 0.12f` 轮廓 | 胶囊筛选标签、试听/切换按钮 |
| **Glass Navigation Bar** | `Color.White.copy(alpha = 0.80f)` | `Color(0xFF161616).copy(alpha = 0.78f)` | 顶部边缘环境微光 | 底部悬浮导航栏 |

### 2.2 弥散光晕（Soft Ambient Shadow）规范
- **禁止硬阴影**：严禁在卡片外层使用深黑高对比度的传统阴影（如 `elevation = 8.dp` 纯黑投影）。
- **同源投射**：
  - 核心操作（橙色 Primary）：投射 `Color(0xFFFFA000).copy(alpha = 0.28f)`，扩散半径 16.dp ~ 24.dp。
  - 功能操作（蓝色/绿色/紫色）：根据操作卡片色相投射同源 20%~25% 透明度的弥散微光。
- **实现方案**：统一采用 `Modifier.softShadow(color, alpha, blurRadius, spread)`。

## 3. 典型页面规范映射

### 3.1 学习主页（Dashboard）
- **Bento 栅格卡片**：圆角统一为 `24.dp`，内边距 `16.dp`。
- **数据呈现**：主指标采用超大字重（`900` / `Black`），辅指标结合微型环形进度指示器。
- **主行动按钮（CTA Button）**：全宽大圆角胶囊，活力橙渐变搭配弥散微光，引导视觉中心。

### 3.2 单词记忆卡片（Learning Card）
- **大字留白**：单词居中突出展示，音标与例句分层排列。
- **四态记忆评分**：底部放置「重来 / 困难 / 良好 / 简单」四键，以柔和背景配合微动反馈，降低用户认知负荷。

### 3.3 假名拼词交互（Spelling Quiz）
- **字符槽位**：采用浅紫/浅蓝圆角卡片作为槽位，已选字符呈现清晰的高亮色彩块。
- **备选气泡**：支持拖拽或轻触选中，带微弱悬浮质感。
- **即时反馈卡片**：答对/答错以全局状态徽章与详细知识点解析卡片顺滑展开。

### 3.4 AI 例文工坊（AI Workshop）
- **双模切换 Tab**：无边界液态滑块设计，自由模式与语法专项一键无缝滑动。
- **半透明毛玻璃输入面板**：在保证阅读对比度的前提下，与底层背景产生毛玻璃透视效果。

## 4. 手势交互与弹性动画准则

1. **手势独占互斥锁**：
   - 交互类控件（如 `LiquidSlider`、拖拽选择）在用户按住或滑动期间，必须设置 `isInteracting` 锁，屏蔽外部状态重置，防止手势被打断或界面卡顿。
2. **释放平滑回弹**：
   - 当用户松手后，若发生数值纠偏或外部同步，采用 `spring(dampingRatio = Spring.DampingRatioMediumBouncy, stiffness = Spring.StiffnessLow)` 物理缓动平滑过渡，禁止瞬间跳变。
3. **震动反馈克制**：
   - 连续滑动条严禁在每一次步进时触发密集震动，仅在边界吸附或关键档位释放时提供极轻微触觉反馈。
