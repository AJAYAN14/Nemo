## 第一部分：自动化测试速验（1 分钟）

在进入手机操作前，请先在终端执行 `:feature:learning` 模块的自动化测试套件。该套件包含 23 个 Delegate 单元测试与高并发合约测试。

### 执行命令（PowerShell 终端）：
```powershell
.\gradlew.bat :feature:learning:testDebugUnitTest
```

### 预期输出：
- 输出 `BUILD SUCCESSFUL`。
- **23 个测试全部 PASS**（0 failures, 0 errors），耗时约 3~6 秒。
- 测试覆盖范围：
  - `RatingDelegateTest` (5项)：评分调度、Lapse惩罚、Leech检测、防抖保护；
  - `QueueNavigationDelegateTest` (7项)：队列遍历、冷却检测、四色状态角标计算；
  - `UndoDelegateTest` (4项)：快照保存、全状态及数据库回滚、反向滑动动画；
  - `CardOpsDelegateTest` (4项)：Bury暂缓、Suspend暂停、Leech双策略（bury/skip）；
  - `SessionLifecycleDelegateTest` (3项)：泛型加载、模式切换、退出清理；
  - `LearningBehaviorContractTest` (5项)：高并发狂点防抖、跨天重置、提前学习判定。

### 环节一：会话启动与模式切换

* **测试模块**：`SessionLifecycleDelegate`、`LearningViewModel`
* **测试目的**：验证泛型会话加载机制、初始队列构建及标题模式状态绑定。

#### 操作步骤：
1. 从主页点击进入【单词学习】。
2. 观察界面加载过程及加载完成后的初始状态。
3. 返回主页，切换并进入【语法学习】。

#### 期望表现（Checklist）：
- [ ] **加载动效**：短暂出现居中三点追逐加载器（`NemoChasingDotsLoader`），无白屏闪退或卡死。
- [ ] **顶部 Header**：
  - 单词模式下标题显示为 **“单词学习”**；语法模式下标题显示为 **“语法学习”**。
  - 右上角圆角胶囊清晰展示 **“剩余 X”**（X 为本组待学总数）。
  - 进度条右侧呈现**四色状态角标**：`[蓝:新学] [青:在学] [绿:复习] [橙:重学]`，数字之和与待学任务匹配。
- [ ] **初始卡片**：第一张卡片平滑展现，默认处于**问题正面**（仅展示单词/例句/发音按键，释义处于折叠隐藏状态）。

> 🚩 **排查重点**：若右上角显示“剩余 0”且直接跳结算页，请检查数据库是否有未背单词数据或模式传参是否正确。

### 环节二：卡片正反面翻转与防抢跑机制

* **测试模块**：`SettingsDelegate`、`SRSActionArea`
* **测试目的**：验证卡片翻面、音频发音以及防抢跑延时强制回想机制。

#### 操作步骤：
1. **基础翻面测试**：在卡片正面，点击底部高亮的 **【显示答案】** 按钮。
2. **发音测试**：点击单词旁边的发音小喇叭图标，确认发音正常播放且动画波纹展示。
3. **防抢跑等待测试**（进阶）：
   - 点击右上角菜单按钮（`...`）-> 勾选 **“显示答案等待”**（时长可通过菜单设置为 2s 或 3s）。
   - 切到下一张新卡片，观察底部按钮：此时按钮应变灰并显示倒计时文本（如 `显示答案 (2s)`）。
   - 在 2 秒内**快速多次点击**【显示答案】按钮。

#### 期望表现（Checklist）：
- [ ] 点击【显示答案】后，卡片正面遮罩平滑淡出，假名、音调核、中文释义完全展开。
- [ ] 底部【显示答案】按钮平滑淡出，替换为 **4 个彩色 SRS 评分按钮**（重来、困难、良好、简单）。
- [ ] 在防抢跑等待期点击按钮时，卡片**不翻面**，触发轻触震动，并在屏幕顶部弹出黄色警告胶囊通知：`“等待中，请先回想 (Xs)”`；倒计时结束后按钮自动变为高亮可点击。

### 环节三：SRS 核心评分与调度算法验证

* **测试模块**：`RatingDelegate`、`QueueNavigationDelegate`
* **测试目的**：验证 Anki/SuperMemo 算法间隔预估、状态迁移、连击累计与切卡动效。

#### 操作步骤：
1. 翻到答案面后，观察 4 个评分按钮上方的预估复习间隔文本（如：`重来 1m`、`困难 10m`、`良好 1d`、`简单 4d`）。
2. **测试【重来 (Again)】**：翻面后点击红色的 **【重来】** 按钮。
3. **测试【困难 (Hard)】**：对下一张卡片点击橙色 **【困难】** 按钮。
4. **测试【良好 (Good)】与【简单 (Easy)】**：依次测试绿色【良好】与青绿色【简单】。

#### 期望表现（Checklist）：
- [ ] **切卡动效**：点击任一评分按钮后，当前卡片**向左滑出**，下一张卡片**从右侧滑入**（`SlideDirection.FORWARD`），过渡流畅无残影。
- [ ] **队列调度**：
  - 点击【重来】：卡片**不移出队列**，四色角标中的青/橙色数字增加，该卡片在后续会被重新出题。
  - 点击【简单】：卡片达成毕业（Graduation），移出今日学习队列，右上角 **“剩余 X”** 准确减 1。
- [ ] **连击反馈**：连续评分【良好/简单】时，卡片右上角的 Combo 连击火焰数连续累加（+1、+2...），打出【重来】时 Combo 归零重置。

### 环节四：高频防抖与并发按键测试（防连跳）

* **测试模块**：`RatingDelegate`、`SRSActionArea`
* **测试目的**：验证 UI 级 200ms 防抖与协程级原子锁互斥机制，杜绝“连点评分连跳两张卡片”问题。

#### 操作步骤：
1. 卡片翻到答案面，显示出 4 个评分按钮。
2. 用两个手指或者最快的手速，对【良好】或【简单】按钮**疯狂快速点击 5~10 次**。

#### 期望表现（Checklist）：
- [ ] **严格只切一张卡片**：无论手速多快，卡片仅平滑切换到紧邻的下一张，**绝不会连跳两张或多张**。
- [ ] **无卡死/无崩溃**：界面不出现假死、黑屏或无响应现象。
- [ ] **数据精准**：右上角剩余任务量严格仅扣减 1，无跳题扣减。

### 环节五：撤销功能全链路回滚验证

* **测试模块**：`UndoDelegate`、数据库 Repository
* **测试目的**：验证快照堆栈、数据库持久化恢复、反向切卡动画与 UI 状态复原。

#### 操作步骤：
1. 记住当前卡片的单词名称（例如：`食べる`），点击【简单】完成评分。
2. 卡片切换至下一个新单词。
3. 观察顶部 Header：返回按键旁边出现**撤销图标按钮**（`Undo ↺`）。
4. 点击该【撤销】按钮。
5. 观察卡片反向恢复，然后再对该卡片重新评分。

#### 期望表现（Checklist）：
- [ ] **反向动画**：卡片以**反向滑动**方式（从左侧滑回，`SlideDirection.BACKWARD`）重新呈现刚才的 `食べる`。
- [ ] **状态完整保留**：卡片恢复后，直接保持在**答案面**（无需重新点击显示答案），方便重新改评。
- [ ] **数据指标回退**：
  - 右上角“剩余待学数”即刻 +1 恢复；
  - 数据库中该单词的复习间隔、复习次数完全恢复到评分前的真实值。
- [ ] **单步安全撤销**：架构采用安全单步快照，点击撤销后立即回滚并消费清空快照，撤销按钮平滑收起隐藏；连续狂点被拦截，杜绝多次并发回滚导致数据错乱。

### 环节七：冷却等待与提前学习 (Learn Ahead)

* **测试模块**：`QueueNavigationDelegate`、`WaitingContent`

#### 期望表现（Checklist）：
- [ ] 界面优雅进入 Waiting 状态，背景呈现粒子/流光光晕，无界面碎裂。
- [ ] 点击【提前学习】时，触发震动与粒子冲击扩散特效，立刻破除冷却锁定，无缝重新切回做题卡片。

### 环节十：卡片自由滑动翻阅、跳题评分队列重排与导航防抖

* **测试模块**：`QueueNavigationDelegate`、`RatingDelegate`
* **测试目的**：验证手势/按键在卡片间前后自由穿梭、400ms 导航防抖以及跳题评分时未作答卡片自动排至队尾机制。

#### 操作步骤：
1. **左右滑动翻阅**：在做题界面，向左轻扫卡片进入下一张（`NavigateNext`），向右轻扫回到上一张（`NavigatePrev`）。
2. **导航 400ms 防抖测试**：用极快的手速连续快速向左滑动 3 次。
3. **跳题评分队列重排测试**：
   - 假设当前队列有 5 张卡片：A、B、C、D、E。
   - 不对 A、B 作答，直接右滑连翻两张至卡片 C。
   - 翻开卡片 C 的答案面，点击【良好】完成评分。

#### 期望表现（Checklist）：
- [ ] 左右滑动切卡方向准确：向前滑切入动画为 `FORWARD`，向后滑为 `BACKWARD`。
- [ ] 高频狂刷滑动时，受 400ms 导航防抖锁保护，严格单张滑动，不会发生跳题飞出或界面白屏。
- [ ] 对 C 评分后，先前被跳过未答的卡片 A、B 会被自动挪移排至本轮队列末尾（新队列变为：D -> E -> A -> B），卡片零丢失。

### 环节十一：语法模式专属操作测试（详情折叠与一键掌握）

* **测试模块**：`StatsTimerDelegate`、`RatingDelegate`
