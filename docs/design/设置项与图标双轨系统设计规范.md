# Nemo 设置项与图标双轨系统设计规范指南

> 版本：v1.1  
> 适用范围：**仅限设置界面、个人中心、二级设置子界面及特定带色块底框的标准设置列表项组件（如 `SquircleSettingItem`）**。  
> 明确排除：**页面级空状态大图标（如 100×100）、全屏占位卡片、特化业务看板插图等。严禁套用到非设置项场景！**  
> 核心原则：**Google Fonts 原生优先、特定设置项 2:3 阶梯、G2 连续平滑曲率、单源同色单容器架构**。

---

## 一、特定设置列表项的 2:3 黄金尺寸比例（非全应用通用）

在**特定带圆角底框的设置列表项与选择项**中，图标尺寸与底框边长保证 2:3 比例。

```
┌────────────────────────────────────────┐
│  42dp G2 Continuous Squircle           │
│                                        │
│         ┌────────────────────┐         │
│         │                    │         │
│  7dp    │     28dp Icon      │   7dp   │
│         │                    │         │
│         └────────────────────┘         │
│                                        │
│                  7dp                   │
│└────────────────────────────────────────┘
```

### 1. 规范参数矩阵与场景阶梯（严防一刀切与教条主义）

> **[!CAUTION] 防 AI 一刀切与带偏硬约束**  
> **1. 28/42dp 仅针对主设置界面（`SquircleSettingItem`）和特定标准行高列表项，绝不是所有带底框图标的标准！**  
> **2. 绝对红线豁免区（严禁 AI 擅自篡改既有尺寸）：**  
> 全应用中的**页面级空状态视图（如 `100dp × 100dp` 容器配 `56dp` 图标等情感化占位视图）、大型业务看板插画、特化功能卡片**，拥有其独立的设计语言与既定尺寸。**严禁 AI 教条式套用 28/42dp 或强行套用 2:3 比例篡改已有尺寸！**  
> **3. 未被用户明确点名要求修改尺寸的已有组件，一律严禁以“规范化”为借口擅自改动！**

| 层级场景 | 容器尺寸 (`Box`) | 内部图标尺寸 (`Icon`) | 留白 (Padding) | 适用典型场景 |
| :--- | :--- | :--- | :--- | :--- |
| **标准级 (Standard)** | **`42.dp`** | **`28.dp`** (2:3) | `7.dp` | **仅限**设置主页列表项 (`SquircleSettingItem`)、个人中心大卡片 |
| **紧凑级 (Compact)** | **`36.dp`** | **`24.dp`** (2:3) | `6.dp` | 二级对话框选项、紧凑型功能面板、小尺寸卡片头部 |
| **微型级 (Mini)** | **`30.dp`** | **`20.dp`** (2:3) | `5.dp` | 列表轻量 Action、弹窗次要选择项、通知栏徽标底块 |
| **极小级 (Micro)** | **`24.dp`** | **`16.dp`** (2:3) | `4.dp` | 标签 Chip 前缀、行内状态提示底块 |
| **【豁免区】空状态大底框** | **保持原尺寸 (如 `100.dp`)** | **保持原尺寸 (如 `56.dp`)** | 场景自定 | **全应用所有空状态插图/占位视图（严禁篡改！）** |

### 2. 比例与防篡改禁令
* **28/42dp 仅针对特定设置场景**：严禁将其作为万能公式到处套用；
* **严禁破坏原有排版密度与空状态尺寸**：严禁将已有的空状态 100×100 缩小为 72/48 或 42/28；
* **两套风格之间切换时，图标物理尺寸必须绝对恒定**，严禁因模式切换产生物理跳动。

## 二、Google Fonts 官方原生图标准入标准

为杜绝第三方 SVG 压缩语法（紧凑粘连）导致的解析报错与字重粗细参差不齐，全应用图标资产实行标准化准入：

### 1. 核心图标准入公理
* **全面转型 Google Fonts 官方原生库**：一律使用 `androidx.compose.material.icons.Icons.Rounded.*` 系列；
* **严禁擅自引入外部第三方图标库**：彻底禁止使用 Lucide、FontAwesome 等外部未经验证的第三方矢量合集；
* **视觉饱满度必须统一为实心 Rounded**：优先选用实心填充（Filled）的 Rounded 图标，杜绝空心线框（Outline）与实心大块图标在同一列表混杂（例如垃圾桶统一使用 `Icons.Rounded.Delete`，禁止混用 `DeleteOutline`）。

### 2. 特殊品牌图标准入白名单 (Whitelisted Exceptions)
仅当 Google Fonts 官方原生库中**确实没有该品牌或业务图标**时，允许自行下载引入规范化矢量文件：
* **白名单资产示例**：
  * GitHub 品牌图标：`ic_github.xml`
  * 特殊学术业务图符（若官方无对应）：需严格经过 AAPT 空格规范化，严禁布尔标志与坐标粘连语法。
* **白名单引入流程**：新增非官方矢量资产必须先在开发台账登记，并经真机 PathParser 语法验证无误后方可收编。

## 三、G2 连续平滑曲率圆角标准

设置项色块底框必须采用三阶贝塞尔连续曲率（G2 Continuous Curvature / iOS Squircle），严禁使用普通圆弧切角。

* **规范调用**：
  ```kotlin
  // 必须使用 RoundedRectangle，底层默认样式为 RoundedCornerStyle.Continuous
  Modifier.background(containerBg, RoundedRectangle(12.dp))
  ```
* **禁止行为**：
  * 严禁使用 `RoundedCornerShape(12.dp)`（普通圆弧在切点处存在二阶导数跳变，会产生视觉折痕）；
  * 严禁硬编码半角或自行计算四角不均等半径。

## 四、双轨色彩映射法则与单容器架构

系统提供“柔和微透”与“活力纯色”两套外观风格，底层必须遵守**“单源同色、同一资产、单容器渲染”**原则。

### 1. 双轨映射法则 (Single Source of Truth)

两套风格接收完全相同的同一个基准颜色（`iconColor`）：

| 风格名称 | 风格特性 | 底框背景色 (`containerBg`) | 图标色 (`iconTint`) |
| :--- | :--- | :--- | :--- |
| **风格 1：柔和微透** | 浅底通透，彩色聚焦 | `iconColor.copy(alpha = 0.15f)` | `iconColor` (100% 原色) |
| **风格 2：活力纯色** | 高饱和实心，纯白反白 | `iconColor` (100% 原色实心) | `Color.White` (纯白反白) |

### 2. 单容器 Compose 纯复用黄金实现范式

严禁在组件内部使用 `if-else` 分裂复制两套 `Box` 与 `Icon`，必须采用计算属性单容器架构：

```kotlin
// 黄金实现范式：SquircleSettingItem 内部渲染实现
val isSoftTranslucent = (iconStyle == SettingIconStyle.SOFT_TRANSLUCENT)
val containerBgColor = if (isSoftTranslucent) iconColor.copy(alpha = 0.15f) else iconColor
val iconTint = if (isSoftTranslucent) iconColor else Color.White

Box(
    modifier = Modifier
        .size(42.dp)
        .background(containerBgColor, RoundedRectangle(12.dp)),
    contentAlignment = Alignment.Center
) {
    if (icon != null) {
        Icon(
            imageVector = icon,
            contentDescription = null,
            tint = iconTint,
            modifier = Modifier
                .size(28.dp) // 严格保持 2:3 黄金比例 (42 * 2/3 = 28dp)
                .graphicsLayer { rotationZ = iconRotation }
        )
    }
}
```
