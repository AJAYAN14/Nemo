# Nemo 全应用 G2 连续平滑圆角迁移台账与规范清单

> 本文档用于系统性记录与追踪 Nemo 项目从 G1 圆角（`RoundedCornerShape`）向 **G2 连续曲率平滑圆角（Squircle / `RoundedRectangle`）** 逐界面推进的迁移进度，防止重复排查与漏改。

---

## 一、 G2 连续圆角设计公理与实现范式

### 1.1 核心差异：G1 vs G2
- **G1 标准圆角（`RoundedCornerShape`）**：由直线与标准四分之一正圆拼接而成，在切点处的曲率存在断崖式阶跃（曲率从 0 突变到 $1/R$），视觉上有明显的“接缝硬角感”。
- **G2 连续平滑圆角（`RoundedRectangle`）**：曲率从平边平滑渐变过渡至顶点，曲率导数连续无断崖（iOS 规范级高阶曲线），呈现极致通透、温润自然的流体质感。

### 1.2 全局规范实现引用
全应用统一采用 `:core:designsystem` 导出的连续曲率形状体系：
- **对称圆角容器 / 卡片 / 标签**：
  ```kotlin
  import com.jian.nemo.core.designsystem.shape.RoundedRectangle
  
  // 替代原 RoundedCornerShape(24.dp)
  shape = RoundedRectangle(24.dp)
  ```
- **非对称四角独立圆角**：
  ```kotlin
  import com.jian.nemo.core.designsystem.shape.UnevenRoundedRectangle
  
  shape = UnevenRoundedRectangle(topStart = 16.dp, topEnd = 16.dp)
  ```
- **胶囊形**：
  ```kotlin
  import com.jian.nemo.core.designsystem.shape.Capsule
  
  shape = Capsule()
  ```
