# Android 调色盘与完整系统色值规范手册

> **官方原生色值保证**：所有颜色代码均只提取自原生规范体系，剔除了所有非原生第三方库色卡，**未作任何算法二次计算或动态取色篡改**。已严格按**浅色模式 (Light Mode)** 与 **深色模式 (Dark Mode)** 进行规范划分，并全量支持 Android Jetpack Compose 与传统 XML 资源体系。
> 
> **特别注意（通道规范）**：本手册中所有八位带透明度的颜色代码，在 Android 体系下统一遵循 **`#AARRGGBB`** 格式（即前两位为 Alpha 透明度通道，后六位为 RGB 颜色通道）。同时在备注栏中附带了 Web CSS 的 `rgba(...)` 规范，避免跨平台开发时通道倒置。
