# Nemo UI 设计规范：分组标题与卡片对齐标准

> **生效范围**：设置页（Settings）、关于页（About）、统计页（Statistics）及所有基于卡片流（Card Stream）构建的二级与三级页面。

---

## 1. 核心对齐与定位规范（Alignment & Spacing）

### 1.1 水平对齐基准（Horizontal Alignment）
| 元素 | 距屏幕左边缘距离 | 对齐状态 |
| :--- | :--- | :--- |
| **分组标题文字（首字起始点）** | **`16.dp`** | 与下方卡片外边框 **完全左对齐** |
| **卡片外边框（`PremiumCard` 轮廓）** | **`16.dp`** | 与标题文字 **完全左对齐** |
| **卡片内部内容（图标与文字）** | **`32.dp`** | 卡片内含 `16.dp` 内边距，视觉微缩进 |

- **绝对左对齐**：标题首字在 X 轴上的起始坐标必须与下方卡片的左边缘（外描边、背景起笔线）严格对齐，处于同一条垂直基准线上（`X = 16.dp`）。
- **避坑红线**：
  - 严禁标题比卡片往左凸出（例如使用 `12.dp`）。
  - 严禁标题在已有 `contentPadding(16.dp)` 的父容器内再次累加 `16.dp` 变成 `32.dp`（这会导致标题比卡片往内缩进）。

---

### 1.2 纵向间距规范（Vertical Rhythm）
遵循格式塔心理学的**亲密性原则（Proximity Principle）**：

```
┌──────────────────────────────────────────────┐
│                  上一组卡片                   │
└──────────────────────────────────────────────┘
                       ↕  20.dp ~ 24.dp（组间间隔）
【分组标题文字】
                       ↕  8.dp（标题与所属卡片紧密间距）
┌──────────────────────────────────────────────┐
│                  本组卡片                     │
└──────────────────────────────────────────────┘
```

- **标题与下方所属卡片间距**：固定为 **`8.dp`**（视觉归属明确，紧凑自然）。
- **标题与上方前一组卡片间距**：推荐为 **`20.dp ~ 24.dp`**（大间距明确划分层级与功能模块）。

## 2. 文本属性与排版规范（Typography）

标题使用全局 `MaterialTheme.typography.titleMedium` 作为基准样式，具体参数约束如下：

| 属性 | 规范值 | 说明 |
| :--- | :--- | :--- |
| **字号（Font Size）** | **`16.sp`** | `titleMedium` 标准尺寸，与卡片主文案形成主次区隔 |
| **字重（Font Weight）** | **`FontWeight.ExtraBold` (800)** | 特黑粗体，在轻量次级灰颜色下仍保持极高辨识度与秩序感 |
| **字体（Font Family）** | **`FontFamily.Default`** | 系统默认无衬线字体（Roboto / HarmonyOS Sans），保证跨端平滑渲染 |
| **行高（Line Height）** | **`24.sp`** | 1.5 倍基线行高，避免换行时文字拥挤 |
| **字间距（Letter Spacing）** | **`0.15.sp`** | 微字距微调，使中英文标题更加紧凑凝练 |

---

## 3. 色彩规范（Color Tokens）

分组标题作为分类导航层级，遵循**弱化辅助层级（Secondary Level）**，不使用高对比度纯黑/纯白，统一绑定动态语义颜色：

- **颜色令牌**：`MaterialTheme.colorScheme.onSurfaceVariant`
  - **浅色模式（Light Mode）**：次级中性灰（Hex: `#475569` / `Slate 600`，或 `0x99000000`）。既清晰可读，又不会抢夺卡片内部核心内容的视觉焦点。
  - **深色模式（Dark Mode）**：微透浅灰（Hex: `#94A3B8` / `Slate 400`，或 `0x99FFFFFF`）。背景深黑时柔和不刺眼，避免眩光。

## 4. 标准代码实现范式

### 4.1 通用组件定义（`SettingsComponents.kt`）
```kotlin
/**
 * 分组标题标准组件
 *
 * 遵循 Nemo Design 规范：
 * 1. 水平边距 16.dp，与 PremiumCard 严格对齐；
 * 2. 纵向边距 8.dp，与下方卡片紧密连接。
 */
@Composable
fun SettingsSectionTitle(
    text: String,
    modifier: Modifier = Modifier.padding(horizontal = 16.dp, vertical = 8.dp)
) {
    Text(
        text = text,
        style = MaterialTheme.typography.titleMedium,
        fontWeight = FontWeight.ExtraBold,
        color = MaterialTheme.colorScheme.onSurfaceVariant,
        modifier = modifier
    )
}
```

### 4.2 界面调用标准范式
```kotlin
// 1. 若 LazyColumn 外层未设置水平 padding（如 AboutScreen）
item {
    SettingsSectionTitle("开源与社区")
    PremiumCard(modifier = Modifier.padding(horizontal = 16.dp)) {
        // 卡片内容
    }
    Spacer(modifier = Modifier.height(20.dp))
}

// 2. 若 LazyColumn 外层已设置 contentPadding(horizontal = 16.dp)（如 SettingsScreen）
item {
    SettingsSectionTitle(
        text = "开源与社区",
        modifier = Modifier.padding(horizontal = 0.dp, vertical = 8.dp) // 覆盖默认参数，避免边距重复叠加
    )
    PremiumCard {
        // 卡片内容
    }
    Spacer(modifier = Modifier.height(20.dp))
}
```
